# 大学四年学习路线（内江师范学院 · 计算机科学与技术 · 就业导向）

> 目标：**本科毕业直接就业**，理想方向：进入大厂 / 成都互联网公司。
> 心法：**学校决定起点，不决定终点。用"实习 + 项目 + 刷题"三块硬货，对冲学历短板。**

---

## 一、认清大厂校招的"四道关"

| 关卡 | 考什么 | 学历作用 | 对策 |
|---|---|---|---|
| 简历关 | 学历 + 实习 + 项目 + 竞赛 | ⭐⭐⭐ 最大 | 用实习/项目/竞赛对冲 |
| 笔试关 | LeetCode 算法题 | 无 | 刷题（最公平） |
| 技术面 | 基础八股 + 项目深挖 + 手撕代码 | 几乎无 | 基础扎实、项目是自己写的 |
| HR 面 | 稳定性、沟通 | 有一点 | 提前准备 |

**结论：学历只影响第一关，笔试面试纯看实力。把简历以外的分拿满，再用硬货顶过简历关。**

---

## 二、三条进大厂的路（可并行）

### 路线 A：暑期实习转正（最推荐）
- 大厂正式校招筛学历，但**实习面试宽松很多**。
- 大三暑期实习 → 表现好直接转正 → 这是双非进大厂最宽的通道。
- 前置条件：大一大二积累的项目和基础。

### 路线 B：中小厂起步，社招跳槽（最稳妥）
- 大四先拿成都/重庆中厂 offer（很多不卡学历）。
- 工作两年后**社招跳槽**大厂——社招看经验，基本不看学历。

### 路线 C：竞赛/开源出名
- 蓝桥杯国奖、天池/Kaggle 比赛、高 star 开源项目。
- 直接写进简历，部分大厂有绿色通道。

## 三、你的隐藏优势：成都

- 内江 → 成都高铁约 1 小时。
- 成都是互联网第五城：腾讯、字节、阿里、美团均有成都分部，另有极米、百词斩、TapTap 等中厂。
- 实习机会多、通勤成本低、可参加技术社区线下活动。

**打法：成都实习 + 成都就业 + 跳板跳槽。**

## 四、四年分年计划（双非定制版）

### 大一（地基年）
- [ ] 高数、线代、离散数学认真学（分水岭，别逃）
- [ ] 学透 Python，或学 C 打底（理解计算机在干什么）
- [ ] 数据结构 + 算法：按专题刷 LeetCode（数组→链表→栈队列→树→图→DP），每天 1–2 题
- [ ] 期末目标：独立写一个 800 行左右的程序（如命令行记账工具）

### 大二（核心课年 ⭐ 最重要）
- [ ] 校内四件套：操作系统、计算机网络、数据库、计算机组成原理
- [ ] 课外加深：CSAPP / CS144（手写 TCP）/ MIT 6.S081（手写 OS）/ CMU 15-445（手写数据库）
- [ ] 学第二门就业语言：Java 或 Go（国内后端岗位最多）
- [ ] 完成第一个全栈项目：带前后端 + 数据库的 Web 应用（如"宿舍二手交易平台"），完整走"需求→设计→开发→部署"
- [ ] 报名蓝桥杯（省奖即有用）

### 大二暑假
- [ ] 进不了大厂就进**成都小公司/创业公司**实习（不卡学历，积累跳板经历）

### 大三（实习年 ⭐ 校招胜负手）
- [ ] 项目打磨到能扛住面试深挖
- [ ] 刷题进入冲刺期
- [ ] 3 月开始投**成都大厂分部暑期实习**（腾讯/字节/美团成都）——翻身核心一战
- [ ] 目标：拿到暑期实习 offer，争取转正

### 大四（收割年）
- [ ] 9–10 月秋招主战场（大厂提前批 6–7 月开）
- [ ] 秋招主投成都 + 全国中厂兜底
- [ ] 能转正最好；不能则中小厂起步，两年后社招进大厂

## 五、如何正确用 AI/Agent 自学

1. **当讲解员**：看不懂代码就问"逐行解释""为什么用这个而不是那个"
2. **禁止复制粘贴**：理解后关掉 agent 自己写一遍，卡住再回去看
3. **让它出题考你**：按难度递增，先别给答案
4. **让它 review 你的代码**：免费 code review 老师
5. **警惕能力错觉**：能看懂 ≠ 会写。别滑向"全让 agent 写、跑通就发朋友圈"

---

## 六、避坑提醒

- 别囤课：收藏 50 个教程 = 一个没学，一次只跟一条主线
- 别只刷题不写项目：笔试考刷题，面试考项目和基础，两条腿走路
- 别因 agent 强就放弃基本功：agent 能帮你写，但不能替你去面试
- 方向选择：大二前都试试（后端/前端/数据），大二下锁定一个主攻
  - 国内就业：后端 Java/Go 需求量最大；前端上手快；AI 方向门槛高，不建议零基础直接冲

---

## 七、检查点（每学期末自检）

- 大一结束：能独立写 500–1000 行程序，LeetCode 简单题不怵
- 大二结束：有 1 个完整全栈项目 + 蓝桥杯参赛经历 + 至少 1 段实习/项目经历可写简历
- 大三结束：有 1 段暑期实习（理想为大厂成都分部），刷题 200+
- 大四开学前：简历上有 2–3 个有深度的项目 + 1 段实习 + 刷题 300+
