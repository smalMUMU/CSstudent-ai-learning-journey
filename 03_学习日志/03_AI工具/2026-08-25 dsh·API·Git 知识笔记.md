# 2026-08-25 dsh · API · Git 知识笔记

> 今天顺带了解的三块知识（非 pi 主线），单独存。

## 一、dsh（DeepSeek Harness）上下文机制
- 上下文窗口：**1,000,000 token**；单次最大输出 **256,000**。
- 压缩规则（`dsh-compaction-basic`）：用到窗口 **80%（80万）** 时自动压缩，**保留最新 16%（16万）**，更早的**总结掉**（保留决策/约束/用户偏好/未决问题/所需数据）。
- 另有 `tool-result-pruner` 剪掉大工具输出，省上下文。
- dsh **大量用缓存**（`cacheReadTokens` 高），长历史重发很便宜。
- 结论：长会话不是问题，**重要的是"一事一会话 + 重要东西写进文件(落盘)"**——因为压缩时细节会丢，只有落盘才真不丢。

## 二、API 与 API Key
- **API** = Application Programming Interface = 两个程序之间**约定好的一套通道/暗号/接口**。你只管"发请求→拿结果"，不用管对方内部实现。
- **API Key** = **通行证/凭证**，证明"你有资格/身份"用这个通道。
- **本质区别**：API 是"桥/通道"（解决**通不通**、怎么沟通）；API Key 是"门禁卡"（解决**允不允许**、你是谁）。
- **什么时候才需要 API Key**：只有"**调用别人家的远程收费/要身份服务**"时才要（如 DeepSeek、OpenAI、GitHub push）。**本地/系统 API、公开资源**不需要（如 `chrome.storage`、Android 系统 API、EasyList 订阅）。
- **做网站**：网站本身不需要 API Key；要调别人服务才要那个服务的 Key；要用户登录那是"身份认证"，不等于 API Key。

## 三、GitHub 文件"打不开"（gitlink / 子模块）
- 现象：文件图标上有个**箭头（→）**，点不开。
- 原因：这是 **gitlink（子模块指针）**，在 `git ls-files -s` 里是模式 **`160000`**。**不是真实文件**，只是"指向另一个仓库某个提交"的指针。
- 为什么出现：对一个**自身带 `.git` 的嵌套仓库**做 `git add`（如 python-pi、project01），git 就把它记成 gitlink；而又**没配 `.gitmodules`/子模块地址**，所以 GitHub 只显示箭头、点不开。
- 解决：`git rm --cached "路径"` 从主仓库移除跟踪；若想并入主仓库，先**删掉该文件夹自己的 `.git`**，再正常 `git add` 作为真实文件提交。
