## 🔖 复习标记说明（刷题记录里用）

| 标记 | 意思 |
|---|---|
| ✅ | 能**独立** AC，隔几天冷写还能过 |
| 🔄 | 需要复习（抄的、提示过、或自己觉得不牢） |
| ❌ | 还没吃透 |

**规矩：就算 AC 了，只要是看着答案 / 被提示着写出来的，一律标 🔄 或 ❌。**
"刚学会立刻重写能过" ≠ "会"。真会要**隔 3 天不看任何东西还能写出来**。

---

## ⚠️ 几条对自己的约定

- **能看懂 ≠ 会写。** 看懂了必须关掉重写一遍，跑通才算数。
- **图解是"看懂"用的，不是"会写"的替代品。** 照着图解 AC 不算数，标记不加分。
- **卡住不许空想**，把变量值一轮一轮写在纸上走一遍 —— 死循环类的问题靠想是想不出来的。
- **不要只看不记。** 不写进这个仓库的，过两周就等于没学。
