## 要默写的骨架（"读入 + 排序 + 输出"通用型）

```python
score = []                                      # ① 容器
while len(score) < n:                           # ② 收够 n 条
    line = input()
    if not line.strip(): continue               # ③ 空行跳过
    name, v = line.split()                      # ④ 拆成两半
    score.append((name, int(v)))                # ⑤ 存成一对（数字要转！）

score.sort(key=lambda p: p[0])                  # ⑥ 次关键字先排
score.sort(key=lambda p: p[1], reverse=True)    # ⑦ 主关键字放最后

for name, v in score: print(f"{name} {v}")      # ⑧ 拆包打印
```

**这 8 行熟了 → T02、T02变体、以及所有"读入+排序+输出"的题都能写。**

## 自查：每一行对应哪个坑

| 行 | 对应你踩过的坑 |
|---|---|
| ② `while len(score) < n` | `for i in range(n)` 数圈 ≠ 数条 → 空行占名额少读一条（**11-15 现场演过**） |
| ③ `if not line.strip()` | 少了 `()` → 静默不跳过空行（**11-15 栽过**） |
| ⑤ `int(v)` | 不转 → 按**字典序**排（`"9" > "1000"`），**样例过、真实数据错**（**11-16 实测过**） |
| ⑥⑦ 排序顺序 | 主关键字必须放**最后一次**（稳定排序） |
| ⑧ `for name, v in` | 拆包：左边名字个数 = 右边元组里的元素个数 |
