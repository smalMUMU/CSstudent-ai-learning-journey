## 0 · 输入输出总骨架（**这是补丁①，最高优先**）

**触发词**：题目里出现"**输入格式 / 输出格式**"两个小标题 ⇒ 立刻停下来，先把这两块写好，再想算法。

**四种读入形态（都能默写才算过）**：

| 形态 | 题目长什么样 | 读法要点（自己敲，不给代码） |
|---|---|---|
| **A 单行一个数** | `5` | 读一行 → 去空白 → 转整数 |
| **B 两行** | `5` 换行 `1 2 3 4 5` | 第 1 行是 n，第 2 行切分成 n 个数（**注意可能是字符串**） |
| **C 多行矩阵** | `3` 换行 `3 行数据` | 先读 n，再循环读 n 行 —— **循环次数别写成 n+1（你的老坑）** |
| **D 多组 / 读到结尾** | 不给组数，直接给到底 | 一次性读完所有 token，**用游标往前走**；或读到空为止 |

**三个必须钉死的点**：
1. **一次性读完 vs 逐行 `input()`**：前者快且不怕空行，后者在带空行的输入上会崩。
2. **数据是数字还是字符串**：切出来的是**字符串**，要算数必须转。
3. **末尾换行 / 多打印的空格**：蓝桥杯是**文本比对**，多一个换行可能就 WA。**格式错 = 全丢分，不是扣分。**

> ✅ 过关方式：我随便给你一段乱格式输入（混空行、混负数、混多组），你**不看资料**写出读取部分。

## 1 · 快读（大输入不超时）
**触发词**：n ≥ 10⁵、时间 1s、`input()` 循环很多次。
**要点**：一次读全部 → 按空白切 → 用列表游标取；**不要**在大循环里反复 `input()`。
**坑**：切出来的都是字符串；`split()` 不带参数会自动处理多个空格和换行。

## 2 · 输出格式
**触发词**："输出一行" / "空格分隔" / "保留 2 位小数" / "输出个数即可"。
**要点**：先想清**是一行、还是每项一行**；列表输出常用"转字符串再拼接"；小数格式化用 `f"{x:.2f}"`。
**坑**：`print(列表)` 会带 `[ ]` 和逗号 —— 蓝桥杯判的是**裸数据**，这直接 WA。

## 3 · 二分 / bisect
**触发词**："有序数组"、"找第一个 ≥ x 的位置"、"答案单调"、"最小化最大值/最大化最小值"。
**要点**：数组里找位置 → 用 `bisect`（左边界 `left` / 右边界 `right` 要分清）；"答案单调"→ **对答案二分**（这是蓝桥杯常考的进阶）。
**坑**：区间写成闭区间还是半开区间，决定 `while` 条件（你 977 卡过三次的那个）。

## 4 · 前缀和 / 差分
**触发词**："多次询问区间和"、"子数组和为 k"、"区间整体加 c"。
**要点**：
- **前缀和**（多次查询区间和）→ 建成 `n+1` 表、**开头补 0**；区间和 = 两次相减（**你的 303 就在这儿没通**）
- **差分**（区间整体加同一个数）→ 只在两端动，最后求前缀和还原
**坑**：`n+1` 表还是 `n` 表，公式差一格；`left=0` 的边界。

## 5 · 计数
**触发词**："出现次数"、"有多少个不同的"、"频次最高"。
**要点**：只问"在不在" → 集合；问"有几个" → 字典 / `Counter`；计数标准写法是"取旧值给兜底再 +1"。
**坑**：**集合会自动去重，一去重次数就没了**（你 389 栽过）；`.get` 当"在不在"判断会被 `0` 骗。

## 6 · 全排列 / 组合 / 笛卡尔积
**触发词**："全排列"、"任选 k 个"、"所有方案"、"n ≤ 8~10"（**看到小 n 就想枚举**）。
**要点**：`itertools` 三个函数分别对应**有顺序**、**无序选**、**可重复**；结果要转成列表再用。
**坑**：`permutations` 与 `combinations` 差一个字母；枚举出来的元素是**元组**。

## 7 · 日期
**触发词**："第几天"、"星期几"、"两个日期相差几天"、"2020 年 2 月"。
**要点**：用 `datetime` 直接算差、直接取星期；闰年规则记 `%4==0 and (%100!=0 or %400==0)`。
**坑**：月份从 **0** 开始还是 **1**；`date` 与 `datetime` 混用；手写日期循环容易差一天（**用库，别手写**）。

## 8 · 数论
**触发词**："最大公约数"、"多少个因数"、"质数"、"a 的 b 次方取模"、"n ≤ 10⁷ 的素数"。
**要点**：
- `math.gcd` 现成；最小公倍数 = 两数积 ÷ gcd
- 快速幂：**内置的 `pow(a, b, m)` 三参数就是**，别手写
- 素数：判断单个数 → 试到 `√n`；要筛一批 → 埃氏筛（**n 到 10⁶ 就够用**）
- 因数个数：试到 `√n`，成对计入，平方数别算两次
**坑**：试到 `n` 而不是 `√n`（TLE）；`1` 不是质数。

## 9 · 进制与字符串
**触发词**："二进制"、"十六进制"、"回文"、"大小写"。
**要点**：任意进制互转都有现成入口（**十进制→二进制/十六进制**、**其他进制→十进制**）；回文用**反转后比对**；大小写差 **32**（你 709 已经会）。
**坑**：转出来的字符串**带前缀**（`0b` / `0x`），要不要去、看题目输出要求。

## 10 · BFS / DFS
**触发词**："最短步数"、"能不能到达"、"连通块"、"迷宫"、"网格里扩散"。
**要点**：**最短步数/最少次数 → BFS（队列）**；**枚举所有方案/连通性 → DFS（递归）**；网格题固定四方向，**必须标记已访问**。
**坑**：DFS 递归层数大要调高递归上限；BFS 忘记出队后立刻标记 → 队列爆炸。

## 11 · 并查集
**触发词**："合并"、"是否属于同一组"、"朋友圈"、"连通块数量"。
**要点**：三件套——**找根（带路径压缩）+ 合并 + 判同根**；初始化时每个点自己是根。
**坑**：合并前要先各自找根再连；只在合并里写压缩、忘了查找里也压缩。

## 12 · 背包 DP
**触发词**："容量/预算有限"、"每个物品价值与重量"、"选或不选"、"最多能装多少"。
**要点**：先定**状态的含义**（"前 i 个物品、容量 j 时的最大价值"），再写转移（**选它 / 不选它 取大**）。
**坑**：**0-1 背包倒着遍历容量，完全背包正着** —— 这个方向错了答案会重复计数（最容易混的一条）。
