## 0.5 答题形态（**这是你目前最大的信息缺口，比报名还影响得分**）

> 蓝桥杯**没有 LeetCode 那种函数壳**，也没有选择题。三种提交形态，各有各的死法。

### 形态 A · 结果填空题
- 页面上是**一个答案输入框**：填最终结果（一个整数 / 一个字符串），**只判对错，不看过程**。
- ⇒ **这里允许"作弊式解法"**：手算、写个暴力程序跑出来、打表、用 Python 大整数直接算 —— **分数照拿**。
- 死法：没有部分分，**错一位 = 0 分**。所以算完必须验算。

### 形态 B · 程序设计题（分数大头）
- 提交**完整源代码**（语言选 Python 3），系统用**隐藏测试点**跑你的程序，**按通过的测试点给分**。
- 输入来自**标准输入**，输出到**标准输出**，系统做**严格文本比对**。
- ⇒ **一道 100 分的题，写暴力也可能拿到 30–60%。** 这是整个策略的地基。
- 死法排序（按赔本程度）：**① 输出格式不匹配（多余空格/空行/方括号） > ② 读入读错 > ③ 超时 > ④ 算法写错**。
  > 注意这个排序：**前两名跟算法无关**。省赛最冤的失分全在这儿。

### 形态 C ·（可能有）代码填空题
- 给一段挖空的代码让你补。**以你当年赛点的实际页面为准**，别按往年传闻准备。

### 白名单（重要）
- **只能用 Python 标准库**：`sys` `datetime` `itertools` `collections` `math` `bisect` `heapq` `string`。
- **不能装 numpy / pandas**，别指望。
- 版本保守：只用你确定有的语法，**别赌新特性**。

### 🔎 10 分钟自验证（我更信你自己看到的东西）
1. 打开官方 OJ 或学校往届模拟赛里**任意一道 Python B 组题**
2. 看提交界面的**按钮**：是「**提交答案**」还是「**提交代码**」？编辑器在哪？有没有语言下拉框？
3. 把看到的信息抄回本文档 ⇒ **这条确认了，M0 才算真过**

## 0.6 "应用型题目多"意味着什么（你的观察是对的，而且对你是好消息）

你说去年 Python B 组"解决应用的题比较多"——**这个观察很准**，它改变的是**优先级**，不是难度：

- **"应用型" = 故事外壳 + 朴素内核**：统计 / 聚合 / 排序 / 模拟 / 枚举 / 背包 / 贪心 / 简单搜索。
  例：**"采药"** 表层是采药，内核是 **0-1 背包**；网格/凹槽类表层是机械装置，内核是**模拟 + 边界**。
- ⇒ **不考高深算法**，真正考的是：**长题干的阅读速度 + 边界考虑 + 输出格式**。
- ⇒ **零件卡优先级调整**：**读入输出 → 计数/聚合/排序 → 暴力枚举(DFS) → 背包 → 模拟 → 二分 → 并查集**。
- ⚠️ 应用型题最大的隐雷：**题干长、样例少、边界藏在文字里**（空数据 / 只有 1 个 / 重复值 / 负数 / 取模）。
  **读题时把"范围与限制"那一行单独抄出来** —— 正是你 26 题栽过的坑（"非递减"是解法的一部分，不是背景描述）。

**只值 30 小时，因为：** 你的核心瓶颈不是"不会算法"，是**留存**（我的画像里那条）。再加一条重线会让已有五条线全部变浅。所以这个计划的设计原则是——**只加补丁，不加课程**。

## 2. 三条铁律（写在最前面，赛场上也适用）

1. **分数最大化 > 优雅最大化。** 蓝桥杯按测试点给分：**能骗到 30% 的分，就不要为了 100% 的解法卡 40 分钟**。
2. **能暴力就暴力。** 每道题先写 O(n²) 版本 → 交 → 再想优化。**先保底，再冲高。**
3. **每周 60 分钟，丢了不补。** 错过一次就跳过（记一行"本周跳过"），**不许欠账**。欠账是你以前所有计划死掉的方式。

## 3. 你要补的只有 3 个补丁

### 补丁 ①：白盒 IO（最高优先，性价比第一）
LeetCode 给你 `def solve(nums):`，蓝桥杯只给你**一堆文本**。**因为格式读错，一道题直接 0 分**——这是省赛最冤的死法。
要练的只有四件事（都能默写才算过）：
- 全部输入一次性读完 → 按空白切开 → 按下标取数
- 第一行是 `n`，第二行是 `n` 个数（最常见形态）
- 多组输入 / 读到 EOF（`while` + 判断是否还有）
- 输出：一行一个 vs 空格分隔；**末尾换行别乱加**

### 补丁 ②：部分分策略（省赛真正的胜负手）
三种"骗分"手段，各配一道题练：
- **暴力**：数据小就硬算（蓝桥杯很多题小数据测试点占 30–60%）
- **打表 / 特判**：结果填空题可以直接手算/写程序枚举，把答案打印出来抄（**填空题不判过程**）
- **Python 红利**：大整数自动无溢出；日期用 `datetime`；全排列用 `itertools` —— 这些在 C 组要手写的东西，你一行就有

### 补丁 ③：12 个高频零件（见 `01_零件卡.md`）
二分、前缀和/差分、计数、全排列组合、日期、数论、进制、BFS/DFS、并查集、背包 DP、快读、输出格式。
**不背、不死记**——**用一次记一条**，用两次就长住。判据同你的老规矩：**不看卡默写出来 ✅**。

## 5. 每周 60 分钟怎么花（固定动作，不用想）

> **固定在一个时间点做**（建议周六上午或周日晚上），**开工第一句话先念到期表**。

```
00–10 分钟｜默写：抽 1 条零件卡，不看卡写出来（写不出 → 这就是本周收获）
10–50 分钟｜做题：1 道（真题 or 改妆题），必须走完"暴力 → 提交 → 再想优化"
50–60 分钟｜记账：在 `02_训练记录.md` 加一行（丢分原因 / 新学到的零件），不到 3 行
```

**"改妆题"是什么（本计划的省钱核心）**：把你**已经 AC 过的 LeetCode 题**（比如 1480 前缀和、724 中心下标、167 双指针）重写成一个**独立程序**——
要求：① 自己写读入（不用函数壳）② 输出格式和蓝桥杯一致 ③ 再写一个暴力版。**这就是把旧题卖出第二次价钱**，也顺手治了你的"复习"病。

## 6. 闸门（不通过就不往下走）

| 闸门 | 判据 | 不过怎么办 |
|---|---|---|
| **零件卡** | **不看卡默写出来**（不是"看懂"） | 留在原地，下周同一张卡再来一次 |

| **整体** | 任何一周：**60 分钟做过 = 过关**（不看产出多少） | — |

> ⚠️ 唯一硬规矩：**真题的分数不进任何"成绩单"**。它只用来暴露零件缺口。别拿它评价自己（你 10-03、10-17 那两次"越急越乱"已经证明了这件事）。
