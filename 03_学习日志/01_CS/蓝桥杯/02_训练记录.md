## 🔖 丢分原因分类（先归类，再谈补什么）

| 代号 | 类别 | 典型表现 |
|---|---|---|
| **F** | **格式** | 输出多空格/多空行/带 `[ ]` 和逗号/小数位数不对 |
| **R** | **读入** | 空行崩了 / 多组没处理 / 字符串没转数字 / 循环次数多一格 |
| **B** | **边界** | 空数据 / 只有 1 个 / 重复值 / 负数 / 全相等 / 取模 |
| **A** | **算法** | 思路方向错（不知道用什么套路） |
| **T** | **超时** | 对了但太慢（复杂度没估） |
| **S** | **语法** | 拼写、全角符号、缩进、`=` vs `==` |
| **—** | 无坑 | 一次过，且自己讲得清为什么 |
