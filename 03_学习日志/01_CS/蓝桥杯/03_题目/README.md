# 🏋️ 题目集（教练出题 · 只出题面，不出答案）

> **规矩第 0 条**：这里**永远没有参考代码**。只给题面、判据、提示方向。
> **每题一个独立子文件夹**，里面固定 4 个文件：

```
T0X/
├── 题面.md        ← 题目 + 坑 + 过关判据 + 提示 + 测试命令
├── 样例输入.txt    ← 直接用，别手输
├── 样例输出.txt    ← 自己比对
└── 我的解答.py     ← 只有注释，字你自己写
```

> 做完在 `../02_训练记录.md` 加一行（勾结果 + 记 F/R 代号）。
> 📌 **出题节奏跟着你走**：你说「要 T0X」，我再出下一题。**不提前囤题**（囤题 = 另一种囤课）。
