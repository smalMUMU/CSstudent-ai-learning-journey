## 一、题面

```
【题目】按原顺序打印名单

输入格式：
  第一行一个整数 n（1 ≤ n ≤ 1000）
  接下来若干行，每行两个数据：姓名 金额，用一个或多个空格分隔
  ⚠️ 其中可能夹有空行（空行不算数据）
  ⚠️ 一共只有 n 条有效数据

输出格式：
  按【输入中出现的原顺序】输出 n 行，每行「姓名 金额」，中间一个空格
  不要输出任何别的东西
```

**样例输入**（见 `样例输入.txt`，第 4 行后面有一个空行，是故意的）：

```
5
张三 12
李四 8

王五 12
赵六 30
钱七 8
```

**样例输出**（见 `样例输出.txt`）：

```
张三 12
李四 8
王五 12
赵六 30
钱七 8
```

## 二、四个坑（这道题埋的，看你中几个）

| # | 坑 | 表现 |
|---|---|---|
| 1 | **空行** | 逐行 `input()` 后直接 `split()[0]` → 空行切出空列表 → `IndexError` |
| 2 | **打印列表** | `print(列表)` → 输出带 `[ ]`、逗号和引号 → **判题直接 WA** |
| 3 | **手滑排序** | 题目要"原顺序"，你顺手 `sort()` → 顺序错 |
| 4 | **多打印东西** | 调试用的 `print(h)`、提示语、空行 → 都算错 |

---

## 三、过关判据（我按这个判，不看你写得漂不漂亮）

1. **空行不崩**（跑到结束正常退出）
2. **输出里没有 `[` `]` `,` `'` 这些符号**
3. **不多打印任何东西**（没有调试行、没有提示语）
4. 不用 `def solution(nums):` 那种 LeetCode 壳，**写在顶层**

---

## 四、三条提示（不给代码）

- **提示 1**：`n` 只告诉你"有几条**有效**数据"，**不保证输入正好 n+1 行**。想清楚：你要按"行数"循环，还是按"凑够 n 条"循环？
- **提示 2**：判据 2 的关键是 —— **你最后交给 `print` 的到底是"一个列表"还是"一个字符串"**？
- **提示 3**：如果你打算用"一次性读完再切"，注意 `split()` 不带参数会自动把**连续空格和换行**都吃掉——这对坑 1 是好事。
