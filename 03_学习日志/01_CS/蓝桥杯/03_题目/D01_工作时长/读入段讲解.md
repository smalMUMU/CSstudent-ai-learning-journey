## 第 2 行 `n = int(input())`

```
n  =  int( input() )
       ↑    ↑
       ②    ①
```

| 步 | 发生什么 | 结果 |
|---|---|---|
| ① `input()` | 要一行 | 字符串 `"4"` |
| ② `int(...)` | 文字 → 真数字 | 数字 `4` |
| ③ `n = ...` | 存进盒子 `n` | `n` 是 `4` |

**用途**：`n` = 题目告诉你有几条数据 → 决定 `range(n)` 转几圈。
⚠️ `n` 是**别人给的数**，不是统计出来的；自己数出来的数叫 `len(列表)`。

**为什么必须 `int()`**：
```python
"4" * 2  →  "44"     # 文字 × 2 = 重复两遍
 4  * 2  →   8        # 数字 × 2 = 真乘法
```

## 第 4 行 `t = datetime.strptime(line, "%Y-%m-%d %H:%M:%S")`

### 这行在干嘛：把**文字**变成**时间对象**

`strptime` 拆开读 = **str**ing **p**arse **time** = "字符串 → 解析 → 时间"

```
line  =  "2022-01-01 07:58:02"     ← 文字
                    ↓  strptime（按说明书解析）
  t   =  一个 datetime 对象          ← 时间对象
```

### 第二个参数是"说明书"

`"%Y-%m-%d %H:%M:%S"` 告诉它哪段是什么：

| 占位 | 含义 | 占位 | 含义 |
|---|---|---|---|
| `%Y` | 四位年 | `%H` | 时（24 小时制） |
| `%m` | 月 | `%M` | 分 |
| `%d` | 日 | `%S` | 秒 |

### 为什么非转不可 —— 一个铁证

```python
"2022-01-01 07:58:02" - "2022-01-02 00:20:05"   # ❌ TypeError：文字不能相减
t2 - t1                                          # ✅ 得到 timedelta（时长）
(t2 - t1).total_seconds()                        # ✅ 时长 → 秒数
```

> **文字只能看，不能减。要算"差多久"，必须先变成时间对象。**

## 第 5 行 `times.append(t)`

把 `t` **塞进列表**。三行的分工是：

```
要一行（line）→ 转（t）→ 塞（times）
```

⚠️ 少任何一个都不行：
- 不要 ①：每轮读同一句
- 不要 ③：读完就扔，**变量每轮被覆盖**
