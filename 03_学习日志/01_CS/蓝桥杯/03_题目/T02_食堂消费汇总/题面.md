## 一、题面

```
【题目】食堂消费汇总

输入格式：
  第一行一个整数 n（1 ≤ n ≤ 1000）
  接下来若干行，每行两个数据：姓名 金额
    · 姓名不含空格
    · 分隔符可能是一个或多个空格
    · 其中可能夹有空行（空行不算数据）
    · 一共只有 n 条有效数据

输出格式：
  按金额【从高到低】排序，每行输出「姓名 金额」（中间一个空格）
  金额相同的，按姓名【从小到大】排（用 Python 默认字符串比较）
  最后一行输出：平均金额，保留 2 位小数
  不要输出任何别的东西
```

**样例输入**：见 `样例输入.txt`（第 4 行是空行，故意的）

**样例输出**：见 `样例输出.txt`

## 二、这题考的 4 个点

| # | 考点 | 提示 |
|---|---|---|
| ① | **跳过空行** | 空行读出来是 `""`，不是 `" "`（你 10-24 栽过） |
| ② | **二级排序** | 先按金额降序；金额相同再按姓名升序。`sort` 可以带 `key`，也可以**排两次**（稳定排序，第二关键字排在后） |
| ③ | **输出格式** | 不能出现 `[ ]`、逗号、引号；最后一行是数字 |
| ④ | **平均分** | 保留两位小数 → `f"{x:.2f}"`。注意"平均"= 总金额 ÷ **人数**（不是 n 以外的什么） |
