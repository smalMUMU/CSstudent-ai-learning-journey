# T02 变体 · 成绩单排序（限时 10 分钟）

> **目的**：昨天 T02 你是"拼出来"的（你自己也说不熟悉）。今天这题**骨架一模一样**，只去掉平均分。
> **判据**：能不能**不看昨天的代码**写出来。写得出来 = 那个结构开始变成你的了。

---

## 一、题面

```
【题目】成绩单排序

输入格式：
  第一行一个整数 n（1 ≤ n ≤ 1000）
  接下来若干行，每行两个数据：姓名 分数
    · 分隔符可能是一个或多个空格
    · 可能夹有空行（空行不算数据）
    · 一共只有 n 条有效数据

输出格式：
  按分数【从高到低】排序，每行输出「姓名 分数」（中间一个空格）
  分数相同的，按姓名【从小到大】排
  不要输出任何别的东西
```

**样例输入**：`样例输入.txt`（第 4 行是空行）

**样例输出**：`样例输出.txt`

---

## 二、和昨天 T02 的差别

| | T02 | 今天 |
|---|---|---|
| 数据 | 姓名 + **金额** | 姓名 + **分数** |
| 排序 | 金额降序 + 姓名升序 | **完全一样** |
| 输出 | 每行一对 + 平均分 | **只有每行一对**（没有平均分） |
| 读入 | `while len(列表) < n` | **完全一样** |

> ⚠️ 差的那一点：**没有平均分** —— 所以 `total` 那套累加器**这题不需要**。
