## ① 一句话核心

**布尔代数把"真/假"变成 0 和 1 去做运算；逻辑门就是用电路实现这些运算的小零件。**

→ 所以整台计算机的一切运算，本质都是**几个最基本的门堆起来**。

---

## ② 必记概念

| 概念 | 记住这一句 |
|---|---|
| **真值表** | 把输入**所有组合**列出来逐个写输出。2 个输入 = **4 行** |
| **NOT（非）** | 取反：1→0，0→1 |
| **AND（与）** | **都真才真**；有一个 0 就是 0 |
| **OR（或）** | **任一真就真**；全 0 才 0 |
| **XOR（异或）** | **恰好一个真**才真 → 输出 0 的只有两种：**两个都真**、**两个都假** |
| **逻辑门** | 实现上面运算的**电路** |
| **晶体管搭门** | NOT = 晶体管 + 电阻；**AND = 两个晶体管串联**；**OR = 两个晶体管并联** |
| **组合门** | NAND = NOT+AND ｜ NOR = NOT+OR ｜ XNOR = NOT+XOR |
| **万能门** | **NAND / NOR** —— 单靠一种就能搭出所有其他门。AND / OR / NOT **单挑都不行** |
| **为什么用二进制** | 电路里**只有两种状态最可靠**：通/断、高/低电压 → 抗干扰、不易出错。⚠️ 跟编译器**无关** |

---

## ③ 概念之间的关系（一条链）

```
真 / 假（布尔值）
   ↓ 运算
NOT / AND / OR / XOR（布尔运算 · 配真值表）
   ↓ 用电路实现（串联=AND，并联=OR，反相=NOT）
逻辑门
   ↓ 拼起来
组合门 NAND / NOR / XNOR —— 其中 NAND、NOR 是万能门
   ↓ 继续往上堆
加法器 → ALU → CPU（集 5、7）
```

**一句话**："串/并"决定"都真才真 / 任一真就真"；"反相"决定取反；往上堆就是整台计算机。

---

## ④ 真实应用案例

- **CPU 每次加法/比较**：底层全是这些门，一颗芯片里堆着几十亿个
- **加法器的进位**：两个数相加时"进位"怎么传，就是 AND/OR 门的组合（集 5 讲这个）
- **编程里对两个数"按位与"**：在机器里就是一片 AND 门在干活
- **手机拍照的每个像素、每一条判断**：最终都落到门电路上

---

## ⑤ 最常见的误区（⚠️ 1、2 条是 2026-11-06 实测踩过的）

| # | 错法 | 正解 |
|---|---|---|
| ⚠️1 | 以为 XOR 只在"**两个都真**"时为假 | **两个都假也是 False**——XOR 只认"恰好一个" |
| ⚠️2 | **跳步骤**算多门链条（"很简单不写了"） | 实测就这样答错了：NOT→AND→NOT 链条答成 0，正解是 1（**漏了最后那个 NOT**）→ **必须一段一段写中间值** |
| 3 | AND / OR 的晶体管接法记混 | **AND = 串联，OR = 并联**（串起来更难通 = 更难为真） |
| 4 | 以为 AND / OR / NOT 是万能门 | 单挑**都不行**；万能的是 **NAND、NOR** |
| 5 | "为什么用二进制"答成"更好编译" | 跟编译器无关，原因是**两种状态最可靠抗干扰** |
