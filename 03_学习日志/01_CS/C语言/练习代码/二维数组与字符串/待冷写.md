## 1️⃣ 3×3 矩阵两条对角线之和

**要做什么**：读 3×3 整数矩阵，输出两条对角线的和（先主后副）。

**核心技巧**：**一个循环就能同时拿两条对角线**

```
主对角线：a[i][i]
副对角线：a[i][N-1-i]      ← 下标之和恒等于 N-1
```

**⚠️ 冷写时要先判断**：3×3 时中心 `a[1][1]` **同时属于两条对角线**——题面要不要去重？

## 2️⃣ 有序数组插入一个数（倒序腾位）

**要做什么**：输入 9 个**升序**整数 + 1 个待插入数 `x`，输出插入后的 10 个数（每行一个）。

**核心技巧**：**从后往前腾位**

```
从最后往前扫：a[i] > x 的，统统往后挪一格（a[i+1] = a[i]）
扫到第一个 ≤ x 的地方，把 x 写进 a[i+1]
```

**⚠️ 冷写陷阱（你的老毛病）**：`for` 循环**结束后**的 `i` 是"比 x 小的最后一个下标"，
所以填的是 **`a[i + 1] = x`**，不是 `a[i]`。**循环变量出循环后的值要想清楚。**

## 3️⃣ 3×3 矩阵原地转置

**要做什么**：读 3×3，**原地**把行列互换，输出 3 行。

**核心技巧**：**只遍历上三角**

```c
for (i = 0; i < 3; i++)
    for (j = i + 1; j < 3; j++)     /* ← 从 i+1 开始，不是 0 */
        交换 a[i][j] ⇄ a[j][i]
```

**为什么 `j` 从 `i+1` 开始**：如果从 0 开始，换过的元素会被再换回去（等于没换）。

## 4️⃣ n×n 矩阵绝对值最大元素及位置（多组测试）

**要做什么**：**多组数据，读到 EOF**。每组给 `n` + n×n 矩阵，输出 `值 行 列`，**行列从 1 开始数**。

**核心技巧三件**：

1. 外层 `while (scanf("%d", &n) != EOF)` —— **多组测试的标准写法**
2. **每轮重置**最大值的行列（`max_row = max_col = 0;`）—— 状态变量初值
3. 比较用 `abs()`（`#include <stdlib.h>`），**存的是原值不是绝对值**

## 5️⃣ 删除字符串中的非英文字母（快慢指针 + 截断）

**要做什么**：读一行（可能含空格），删掉所有非英文字母，输出结果。

**核心技巧：快慢指针原地覆盖**

```
快指针 i 扫全文 → 是字母就抄给慢指针：s[j++] = s[i]
慢指针 j 指"下一个要写的位置"
最后：s[j] = '\0';          ← 关键！手动截断
```

**⚠️ 新概念：`'\0'`**
C 的字符串靠 **结尾的 `'\0'`** 判断"到哪结束"。你只把字符往前搬、**不补 `'\0'`**，
尾部残留的旧字符会一起被打印出来。

**读入方式**：`fgets(s, sizeof(s), stdin)` —— 能吃空格；
`scanf("%s")` **遇到空格就停**，这题会少读。
