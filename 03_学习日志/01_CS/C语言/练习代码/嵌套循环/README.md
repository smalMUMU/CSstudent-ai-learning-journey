## 第 1 关 · 直角三角形（15 分钟内）

输入正整数 `n`（1 ≤ n ≤ 20），输出 n 行，第 i 行有 i 个 `*`：

**样例**：`4` →
```
*
**
***
****
```

**脚手架**
```
外层 for：i 从 1 到 n        ← 管"第几行"
内层 for：j 从 1 到 i        ← 管"这一行打几个"
外层末尾：换行
```

**自检**：`n = 1` 时必须只输出一行一个 `*`。

## 第 2 关 · 九九乘法表（分水岭）

输出 1~9 的乘法表（下三角即可）：

**样例格式**（第 i 行输出 `j*i=积`，用 `%-4d` 或 `%（4 宽）` 对齐，行间空格自定）：
```
1*1=1
1*2=2   2*2=4
1*3=3   2*3=6   3*3=9
...
```

**为什么是分水岭**：这里 `i` 和 `j` **同时出现在输出里**，你必须清楚"谁是行、谁是列"。

**自检**：第 9 行必须有 9 个式子；第 3 行必须有 3 个。

## 第 3 关 · 菱形（进阶，可选）

输入奇数 `n`，输出 n 行的菱形（上三角 + 下三角，每行需要**先打空格**）：

**样例**：`5` →
```

```
