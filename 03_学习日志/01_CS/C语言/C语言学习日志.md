## 🚨 老毛病 #1：让一个变量干两件事（**跨三门课的同一个病**）

> 2026-10-24 我自己点出来的："我让 i 干两件事是我的老毛病了。"
> 查了一遍历史记录，**这不是 C 的问题，是贯穿高数、Python、C 的一个习惯**。

**病根一句话**：
> **一个变量同时扮演两个角色，而这两个角色的数值并不同步 → 必然错，而且编译器不报错。**

### 证据链（同一模式，7 次）

| # | 学科 / 场景 | 一个变量当了哪两个角色 | 后果 | 出处 |
|---|---|---|---|---|
| 1 | 高数 T5 梯度下降 | `x` 既当"位置"又当"循环计数" | 覆盖起点、迭代乱掉 | 10-01 |
| 2 | 高数 T6 牛顿法 | `for x in range(1,6)`：`x` 被 range **每轮重置** | 根本不迭代，输出不收敛 | 10-02 |
| 3 | LeetCode 26 | `k` 同时当"看"（右手探路）和"放"（左手写入） | 整个思路从前提上跑偏 | 10-07 |
| 4 | LeetCode 118 杨辉三角 | 外层变量（管哪一行）和内层变量（管这一行第几对）**套反** | `mid` 跨行累加、输出错乱 | 10-11 |
| 5 | C 练习2-14 | `i` 既当"第几项"又当"分母上限" | 23 项只加了 12 项 | 10-24 |
| 6 | C 练习2-15 | `i` 既当"第几项"又当"分母" | 分母 1,4,7 根本写不出来 | 10-24 |
| 7 | C 习题3-2 | `m`/`n` 语义混（车速/限速用反） | 永远输出 `OK` | 10-24 |

### 判据（写循环前，强迫自己问一句）

> ## **"这个变量是【数数的】，还是【被算的】？"**
> **两个角色 → 两个变量。**

| 情况 | 解法 | 例子 |
|---|---|---|
| 两个角色**不同步**（1,2,3… vs 1,4,7…） | **拆成两个变量** | `k` 数项 + `den` 走分母 + `den += 3` |
| 一个是另一个的**函数**（分母 = 3k−2） | 只留一个，另一个**用公式算** | `1.0 / (3 * k - 2)` |
| 两个角色**同步**（N 项且分母到 N） | 可以合并，但**要在注释里写清** | 2-13 的 `1.0 / k` |

### 为什么这个毛病特别难改

1. **编译器永远不提醒**——它不报错、不警告，甚至给你一个"看起来合理"的答案。
2. **省变量看起来更聪明**——少写一个变量像个"优化"，其实是在埋雷。
3. **它跨语言、跨学科复发**——换了语言、换了科目，习惯还在。

### 落地的两个动作

- **写循环前先写一行注释**，把每个变量的角色钉死：
  ```c
  /* k = 第几项（计数器）;  den = 分母（每次 +3） */
  ```
- **答案不对时，第一个查的不是公式，是"有没有变量在兼职"**。

## 🖨️ printf 格式串速查（**不用背，查这个** · 2026-10-24 建）

> 触发点：10-24 做 2-12 时"占位符掌握不完全"，把 `%d   %.1f`（手打空格）当成对齐办法。

**占位符 = 格式说明符 = 一个挖好的坑，运行时把值填进去。它是四个槽位拼出来的：**

```
%        6        .1        f
│        │        │         │
①开关   ②最小宽度 ③小数位数  ④类型
```

| 写法 | 打印效果 | 用在什么场景 |
|---|---|---|
| `%d` | `32` | 普通整数 |
| `%5d` | `[   32]` | 整数占 5 宽、靠右 |
| `%-5d` | `[32   ]` | 靠左 |
| `%05d` | `[00032]` | 补零 |
| `%f` | `1.111000` | 浮点默认 **6 位小数** |
| `%.1f` | `1.1` | 只限小数位数，不占宽 |
| **`%6.1f`** | `[   1.1]` | **占 6 宽 + 1 位小数、靠右（2-12 用这个）** |
| `%-6.1f` | `[1.1   ]` | 同上去左对齐 |
| `%c` | `A` | 单个字符 |
| `%s` | `hello` | 字符串 |
| **`%%`** | `%` | **打印一个真实的百分号** |

### 三条铁律

1. **个数和类型必须一一对应**：占位符几个、参数几个，顺序和类型都要对上。错一个 → 打印垃圾，**而且不一定报错**（3-2 的 `%.L` 被读成 `%Li` 就是这么来的）。
2. **`%%` 才是字面上的 `%`**：格式串里 `%` 是"开关"，后面紧跟的字会被当成指令吃掉。
3. **宽度是"最小"宽度，不是固定宽度**：值比它还长就整个打印出来，**不截断、不错位**。

### 空格怎么数（比背规则可靠）

> **要补的空格数 = 宽度 − 值本身占几个字符**
> 例：`%6.1f` 打印 `-17.2` → 值占 **5** 个字符（`-17.2`）→ 补 **1** 个空格。
> 记牢两点：**负号算一个字符**；**小数点算一个字符**（但不算"一位数字"）。

### 自查动作（数不准时别猜）

```c
printf("[%6.1f]\n", 123.4);   /* 用方括号把空格框出来，一眼看清 */
```

## ➗ 数列通项怎么读（等差 · 2-13~2-15 连考三题的共同技能）

> 触发点：2-15 把分母写成 `i + 3`（得到 4,5,6,7…），抄了上一题的形状，没读题目给的数列。

**一条公式**：`a_k = 首项 + (k − 1) × 公差`

| 分母序列 | 公差 d | 通项 | 出处 |
|---|---|---|---|
| 1, 2, 3, 4 | 1 | `k` | 2-13 |
| 1, 3, 5, 7 … | 2 | `2k − 1` | 2-14 |
| 1, 4, 7, 10 … | 3 | `3k − 2` | 2-15 |
| 2, 4, 6, 8 | 2 | `2k` | — |

**三题的模板完全一样，只有通项不同**：

```c
for (int k = 1; k <= N; k++)      /* N 永远 = 项数 */
    S += 符号 * 1.0 / (通项);
```

- 2-13：通项 `k`，全正 → `1.0 / k`
- 2-14：通项 `2k-1`，全正 → `1.0 / (2*k-1)`
- 2-15：通项 `3k-2`，**交错** → 用 `sign` 变量，`sign = -sign`

### 两种写法都能写出来，选一个趁手的

**写法 ①：分母自己每次 +公差（两个变量，最直观）**
```c
int den = 1;                   /* 分母：1,4,7,10… 自己递增 */
for (int k = 1; k <= N; k++)   /* k 只负责"数到第几项" */
{
    S += sign * 1.0 / den;
    sign = -sign;
    den += 3;                  /* ← 每轮 +3 */
}
```

**写法 ②：用通项算（一个变量，更短）**
```c
for (int k = 1; k <= N; k++)
    S += sign * 1.0 / (3 * k - 2);
```

> ⚠️ **别让一个变量同时干两件事**：`i` 既是"第几项"（1,2,3…）又是"分母"（1,4,7…）——这两个数不同步，所以必然错。要么分成两个变量（写法 ①），要么用一个、另一个用公式算（写法 ②）。

**最便宜的探针**：先跑 `N = 1`，输出必须等于第一项（2-15 应为 `1.000`）。错在这一项，后面全错。

### 📅 2026-10-24 · 分支与循环（练习2-12 温度表 + 习题3-2 超速处罚）

**🎯 今天搞懂的一件事**：`printf` 的格式串是**一门小语言**——`%` 是开关，后面跟的是"指令"；宽度要靠**占位符**声明，不能靠手打空格。

**1. 核心概念（我现在理解的）**
- `%6.1f` = 占 6 宽、1 位小数、靠右；要补的空格 = 宽度 − 值字符数。
- 两个整数相除，C 只留整数部分；要小数必须有一边是浮点数（`5.0`）。
- C **不支持** `a <= b <= c` 这种链式比较，必须拆成两个比较用 `&&` 连。
- `%%` 打印字面的百分号。

**2. 我在习题里踩的坑**
- 2-12：`5 * (i - 32) / 9` 整数除法 → `1.0`；`"%d   %.1f"` 手打空格 → 负温度错位；`Invalid` 少了句点；`lower <= upper <= 100` 假链式比较。
- 2-12 还漏了 `upper > 100` 的判断。
- 3-2：`%` 没转义；`m`/`n` 与题面输入顺序相反 → 永远输出 `OK`；`x <= 50` 把 50% 判成罚款。
- 2-13：`double S += 1.0/N;` 把"声明"和"累加"合成一句（编译报错）；`S` 声明在循环体里（作用域出不去）；通项写成 `1.0 / N` 而不是 `1.0 / i`；循环 `i` 从 0 开始（第 1 项是 `1/1`，该从 1 起）。
- 2-14：把 `N` 当成**分母上限**（`i <= N; i += 2`）→ 只加了 12 项。理解偏差：**"有 N 项的奇数数列" ≠ "N 个整数里的奇数项"**。
- 2-15：分母写成 `i + 3`（得到 4,5,6,7…），抄了上一题的形状；且 `1 / (i+3)` 是整数除法 → 全部为 0，输出 `0.000`。**sign 交替符号的写法是对的**（首项为正、先加再翻号）。

**3. 我的复述（一句话，用我自己的话）**
> 占位符就是"先挖个坑，让 printf 按宽度规则把值填进去"——坑里能规定宽度和小数位，坑的个数和类型必须跟后面给的值一一对上。
