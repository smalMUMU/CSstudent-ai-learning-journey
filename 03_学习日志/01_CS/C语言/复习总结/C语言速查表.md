## ① 一句话核心

**C 不做任何猜测——`5/9` 就是 0，`%d   %.1f` 就是 3 个死空格。代码只认你写出来的东西。**

→ 所以"对"的标准不是"看着对"，而是：**每个角色、每个宽度、每个边界，都显式写对。**

## ② 必记概念

| 概念 | 记住这一句 |
|---|---|
| **占位符** | `%[宽度][.精度]类型` = 一个坑，运行时把值填进去 |
| **`%6.1f`** | 占 6 宽、1 位小数、靠右。**补空格数 = 宽度 − 值字符数**（负号/小数点各算 1 个） |
| **`%%`** | 打印一个**字面的** `%`；否则 `%` 后面的字符被当格式指令读掉 |
| **整数除法** | 两侧都 int → **砍掉小数**（`5/9 = 0`）。要小数就让一边变浮点：`5.0/9` |
| **链式比较** | C **不支持** `a<=b<=c`（Python 支持）。必须 `a<=b && b<=c` |
| **累加器三件事** | ① 循环**外**声明并 `= 0` ② 循环**内** `+=` ③ 循环**后**才用 |
| **变量角色** | 一个变量只干一件事：**数数的**（计数器）还是**被算的**（数据） |
| **前 N 项的和** | **N 是项数**（跑几圈），**不是分母的终点** |
| **通项（等差）** | `a_k = 首项 + (k−1)×公差` → 如 `1,4,7,10…` = `3k−2` |
| **交错符号** | `int sign = 1;` → 每轮 `S += sign * …;` 然后 `sign = -sign;`（首项必须为正） |
| **累乘器** | 初值 = **1**（乘法单位元）；累加器初值 = **0**（加法单位元） |
| **变量放循环外还是循环内** | **放循环外** → 只初始化一次、跨轮累积（累加器 `S`）；**放循环体内** → 每轮重新执行声明、等于每轮重置（每项都要重算的累乘器 `f`）。⚠️ 循环体内声明的变量，**出了循环就看不见** |
| **整数次幂** | 别用 `pow`（返回 `double`，约 16 位有效数字就失准）→ 用 `long p = 1; p *= 3;` 配 `%ld` |
| **值 vs 类型** | `pow(3,9)` 的**值**是整数 19683，**类型**是 `double`。要精确整数就用 `int`/`long`；`double` 是"约 16 位有效数字的**近似**容器" |
| **递推 / 滚动变量** | 第 i 项 = **上一项的简单变换**（`f *= i`、`p *= 3`、`nums[i] += nums[i-1]`）→ 一个变量 + 一层循环就够，比"每项从头重算"的嵌套少一个量级（O(N) vs O(N²)）。⚠️ **更新顺序不能反**（先升级再使用） |
| **函数三件套** | **返回什么、叫什么、吃什么** = 返回类型 / 函数名 / 参数表。非 `void` 必须有 `return`；定义要写在 `main` **前面**或先写原型 `double fact(int n);`；**形参是副本、按位置传**。⚠️ C 不能嵌套定义函数 → 细节见日志「🧩 函数语法细节」 |
| **库函数的脾气** | `pow` / `sqrt` / `fabs` / `sin` / `log` **一律返回 `double`**（因为它们要能算小数次幂） |
| **输出格式** | 跟样例**逐字符照抄**：标点、空格、大小写、`Invalid.` 的句点 |
| **`-Wall`** | 免费老师。链式比较、`%` 转义错误都是它先发现的 |

## ③ 概念之间的关系

```
   题目给的数列
        │ 读"公差"
        ▼
   通项 a_k ───────────► 1.0 / (通项)      ← 分子必须写 1.0
        ▲                     │
        │                     ▼
   分母怎么变，先算出来   S += sign * …
   （别让 k 兼职）            │
        │                     ▼
   k 只负责"第几项"      printf("sum = %.3f")
   for (k=1; k<=N; k++)         │
   ↑ N 永远是项数         宽度/精度/%%/逐字照抄
```

- **变量角色**决定写法：角色不同步 → 拆两个变量；一个是另一个的函数 → 用通项公式。
- **整数除法**破坏的是"值"；**格式串**破坏的是"样子"。**两者独立，只修一个照样错。**
- **通项**一错，符号/精度全白搭——**先通项，再代码。**

## ④ 一个真实应用案例

**高速公路超速处罚（习题 3-2）**：输入限速与车速 → 算超速百分比 → 按阈值分三档 → 按**固定格式**输出处罚。

一个 20 行的程序里同时踩了三个真坑：
1. **整数除法** → 百分比算成 0，永远 `OK`
2. **`%` 没转义** → `%.L` 被读成 `%Li`，去读一个不存在的 `long long`
3. **边界归属** → 恰好 50% 该吊销还是罚款

> 现实里所有"**按阈值分级 + 打印报表**"的代码都是这个形状：成绩等级、告警分级、费率分档、税率计算。

## ⑤ 最常见误区

| ❌ 误区 | ✅ 真相 |
|---|---|
| 手打空格来对齐 | 用 `%6.1f`——宽度是**规则**，空格是**字形** |
| `5 * (x - 32) / 9` | `5.0 * (x - 32) / 9`（两个 int 相除必砍小数） |
| `if (a <= b <= c)` | `if (a <= b && b <= c)` |
| `double S += ...` | 声明只能 `=`；`+=` 用于**已存在**的变量 |
| 累加器声明在循环里 | 声明在**循环外**（花括号 = 作用域边界） |
| `i` 既当项号又当分母 | 拆两个变量，或用通项算分母 |
| "前 N 项" = 分母加到 N | N 是**项数**（2-14 因此只加了 12 项） |
| 样例过了就提交 | 自己造**极端输入**：负数、边界、`N=1`/`N=2` |
| 看到 warning 不管 | `-Wall` 全开，warning 是白送的分 |
| 抄上一题的公式形状 | 先读本题数列的**公差**，再写通项 |
| 设了 `sign` 变量却**忘了每轮翻转** | 循环体里必须有一行 `sign = -sign;`（否则从第 2 项起永远同号） |
| 看到"部分正确"就以为快对了 | 往往是**小 N 碰巧对**（前 2 项在两个版本下相等）→ 拿 `N=3` 以上验 |
| 用 `pow` 打印整数（配 `%f`） | **整数次幂用整数累乘**：`long p=1; p*=3;` 配 `%ld`。`double` 从 `3^38` 起就错（差 89） |

## ⑦ 快速自测（先答，再对答案）

1. `printf("%6.1f", -17.2)` 前面补几个空格？
2. `5 * (10 - 32) / 9` 在 C 里等于多少？
3. `if (1 <= 5 <= 100)` 这个条件是真是假？为什么？
4. `1 − 1/5 + 1/9 − 1/13 + …` 前 N 项，第 k 项的分母是什么？
5. 这段为什么编译不过：`for (i = 0; i < 3; i++) { double S += 1.0 / i; }`

<details>
<summary>答案（先自己答完再点）</summary>

1. **1 个**。`-17.2` 占 5 个字符（`-`、`1`、`7`、`.`、`2`），`6 − 5 = 1`。
2. **−12**。`5 × (−22) = −110`，`−110 / 9` 整除**向零截断** → −12。
3. **恒真**。先算 `1 <= 5` 得 **1**，再算 `1 <= 100` 得 **1**。C 不支持链式比较。
4. **`4k − 3`**（分母 1, 5, 9, 13…，公差 4，首项 1）。
5. 两条：① **声明时不能 `+=`**，只能 `= 初值`；② `i = 0` 时 `1.0 / 0` 是除以零（**应从 1 开始**，且累加器要声明在循环外）。

</details>
