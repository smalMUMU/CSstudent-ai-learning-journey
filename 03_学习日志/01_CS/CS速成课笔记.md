### 🎯 最该补的 3 个知识漏洞

**漏洞①【最优先】机器怎么把"数"算出来：二进制表示的完整含义 + 逻辑门 → ALU → 加/减法**
- 证据：Q1 后半（256 / 255 不知道）+ Q3 全错 + Q2 的 XOR 半懂
- 缺的不是"会转二进制"，是**位数意识**（8 位 = 256 个值、最大 255）和**用门电路做运算**这条链
- 对应集数：**集 1–5**
- 为什么最优先：**后面所有内容都踩在这块上**（内存、CPU、字符编码、压缩、加密的信号全从这儿来）

**漏洞②【次优先】内存与存储层次 + 操作系统（到底谁在管内存）**
- 证据：Q4 全错 + Q9 全错（=《CS50x学习日志》漏洞①"内存模型"，同一块）
- 具体空的是：寄存器 / RAM / SSD 的**速度·容量·断电差别**，和**"为什么要分这么多层"**；进程、虚拟内存、隔离
- 对应集数：**集 6、18、19**（+ 集 7–9 收口）
- 为什么优先：**一份时间两份收益**——CS50 Week 4【内存】和 LeetCode 的"变量/引用"都靠它

**漏洞③【第三】数据结构与权衡 + 数量级直觉**
- 证据：Q8 全错（还猜反了）+ Q7 只能给机制、给不出前提和步数（= CS50 漏洞②③，同一块）
- 具体空的是：**数组 vs 链表的取舍**、哈希表"为解决什么而生"、**O(log n) 到底是多少步**
- 对应集数：**集 13、14**
- 为什么优先：**它同时是 CS50 Week 3/5、蓝桥杯、笔试面试的正门**

> 第二梯队（重要但不必现在补）：**集 28–30 网络与互联网、集 33 加密、集 31–34 安全与 AI**。
> 网络那几集对 agent / API 主线很值，建议**放到寒假前后**看，那时能立刻用上。

### 一、三条规矩

1. **不许"一次刷完"**：每集看完必须留 2 样（我学到的 / 我没懂的），**填完才看下一集**——这是"能力错觉"的防线。
2. **看课不动手，动手不靠看课**：速成课只负责"看一眼机器长什么样"；要动手写代码/跑命令的**全交给 CS50x 和 LeetCode**，两边不重复消耗。
3. **看完必答**：每集看完，立刻回来答本卷**对应的那道题**——**答不出来 = 这集白看**，回去重看（每集 10 分钟，重看很便宜）。
