LeetCode 78. 子集 (Subsets) 中等 · 回溯 / 迭代 / 位运算

给你一个整数数组 nums（元素互不相同），返回该数组所有可能的子集（幂集）。共 2n 个子集。

快捷键：Space 播放/暂停 · ←/→ 单步 · R 重置
核心直觉：为什么 n 个元素恰好有 2n 个子集？ 因为对每个元素 nums[i]，都只有「不选」或「选」两种命运。你的代码先递归走「不选」分支，再 append 走「选」分支，最后 pop() 恢复现场，等 i == n 到达决策树叶子时记录结果。
易错点提醒：必须写 res.append(path[:])（浅拷贝快照）！如果直接写 res.append(path)，所有结果都指向同一个列表，最后 pop() 清空后 res 会变成一堆 []。

四种解法横向对比（为什么推荐学习迭代法与枚举起点法？）
解法 时间复杂度 空间复杂度（不含输出） 递归节点数 (n=3) 特点与适用场景
1. 选/不选回溯（你的代码） O(n · 2n) O(n) 栈 + path 15 个节点 思维最直观，每个元素二选一；只在叶子节点 i == n 收集结果。
2. 枚举起点回溯 O(n · 2n) O(n) 栈 + path 8 个节点 树节点数减半！ 每个节点都是合法子集，入栈即收集；更容易迁移到 LeetCode 90（子集 II 去重）。
3. 迭代倍增法 O(n · 2n) O(1) 无递归栈 无递归 代码最短（仅 4 行）！ 每遇到一个新数字，就把现有所有子集复制一份并加上它，无爆栈风险。
4. 位运算枚举 O(n · 2n) O(1) 无递归栈 无递归 用 0 到 2n-1 的二进制位直接表示选/不选，天然对应幂集数学定义。
