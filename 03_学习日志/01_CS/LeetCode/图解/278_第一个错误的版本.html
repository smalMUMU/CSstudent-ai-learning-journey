第一个错误的版本 (First Bad Version)

逐步观察二分查找如何用 left、right、mid 夹逼出第一个坏版本，理解为什么最后 return left。

初始化 当前搜索区间: [0, 10]

核心直觉：为什么循环结束时可以直接 return left？

  • left 左侧的所有版本都已被证实是好版本（因为只有遇到 not bad 时才令 left = mid + 1）。
  • right 右侧的所有版本都已被证实是坏版本（因为只有遇到 bad 时才令 right = mid - 1）。
  • 当 while left <= right 结束时，必定有 left == right + 1：此时 right 停在最后一个好版本，而 left 恰好停在第一个坏版本上！
