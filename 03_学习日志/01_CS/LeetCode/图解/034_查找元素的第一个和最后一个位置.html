在排序数组中查找元素的第一个和最后一个位置

核心思想：利用 erf(target, nums) 寻找第一个 >= target 的下标，再通过 erf(target + 1, nums) - 1 锁定右边界。

为什么这样写能一次搞定左右边界？

1. erf(target, nums) 的本质

循环条件 left <= right 是闭区间二分。只有 nums[mid] < target 时才移动 left，否则一律左移 right。循环结束时 left 必停在第一个 ≥ target 的下标。

2. 巧妙复用求右边界

把目标换成 target + 1，调用同一个 erf 会找到第一个 >= target + 1 的位置（即最后一个 target 的下一位），再减 1 就精准落在右边界 num2。

3. 为什么最后必须校验？

如果 target 比所有元素都大，num1 == len(nums)（越界）；如果 target 不存在但落在数组中间，nums[num1] > target。因此必须判断 num1 < len(nums) and nums[num1] == target。
