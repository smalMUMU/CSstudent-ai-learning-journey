# LeetCode UI 交互图解

这个文件夹专门放**可交互的算法可视化页面**（HTML，双击用浏览器打开）。

## 命名规则

```
三位题号_题目名.html
```

例：`088_合并两个有序数组.html`、`101_对称二叉树.html`

题号补三位（`1` → `001`），这样按文件名排序就是按题号排序。

## 用法提醒

- **需要联网**：这些页面都从 CDN 加载 Tailwind / 图标 / 字体。**断网打开会变成白底无样式**（按钮还能点，但很丑）。
- **是"看懂"用的，不是"会写"的替代品**。看完照样要关掉冷写一遍。
- 页面上对不上题解的地方，别默认它对 —— 2026-11-07 那张 101 的页面上代码就用了 JavaScript 的 `//` 注释，Python 要用 `#`。**抄进 LeetCode 会直接报语法错。**
