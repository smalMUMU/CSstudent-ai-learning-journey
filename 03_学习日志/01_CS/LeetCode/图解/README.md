# LeetCode UI 交互图解

这个文件夹专门放**可交互的算法可视化页面**（HTML，双击用浏览器打开）。

## 命名规则

```
三位题号_题目名.html
```

例：`001_两数之和.html`、`088_合并两个有序数组.html`

题号补三位（`1` → `001`），这样按文件名排序就是按题号排序。

# 使用方法

## ⚠️ 先说一个坑

**在 GitHub 网页上点 `.html` 文件，只会显示源码，不会变成网页。**

这是 GitHub 故意的安全策略，不是文件坏了。想在浏览器里看交互效果，走下面任一条。

---

## 方式一：本地打开（最省事）

文件就在本机，**双击就行**：

```
F:\GitMUMU\03_学习日志\01_CS\LeetCode\图解\001_两数之和.html
```

用 Chrome / Edge 都可以，不需要起服务器。

---

## 方式二：raw.githack（在网页上看，零配置）

把 GitHub 上的原始文件**当成网页渲染**出来，样式和动画都正常。

打开这个地址（换题号即可看其他题）：

```
https://raw.githack.com/smalMUMU/CSstudent-ai-learning-journey/main/03_学习日志/01_CS/LeetCode/图解/001_两数之和.html
```

**地址格式记法：**

```
https://raw.githack.com/<用户名>/<仓库名>/<分支>/<文件路径>
```

⚠️ **前提：仓库必须是公开的（public）。** 如果是 private，这条路走不通。
⚠️ 这条**没有实测过**，第一次用请自己确认能不能打开。

---

## 方式三：GitHub Pages（一劳永逸，配一次）

配好之后得到一个固定网址，**手机能打开，也能发人**。

**配置步骤：**

1. 打开仓库 → **Settings**
2. 左侧栏找到 **Pages**
3. Source 选 **Deploy from a branch**
4. 分支选 **`main`**，目录选 **`/ (root)`** → **Save**
5. 等 1–2 分钟

**之后地址是：**

```
https://smalMUMU.github.io/CSstudent-ai-learning-journey/03_学习日志/01_CS/LeetCode/图解/001_两数之和.html
```

⚠️ **两个坑：**

- **Pages 要求仓库 public**（private 需要付费）
- **中文路径在 URL 里会变成 `%E8%A7%A3%E5%9B%BE` 这种**，Pages 有时会 404。**真打算长期用 Pages，就把 `图解` 改成 `diagrams`**，文件名也尽量用英文或纯数字。

---

## 看这些图的正确姿势

1. **先自己做一遍题**，卡住了再打开这张图 —— 顺序反了，图就变成"看图背答案"
2. **一步一步点，不要直接拖到最后** —— 价值全在中间那些步骤里
3. **看完关掉，冷写一遍** —— 图是"看懂"用的，不是"会写"的替代品
4. **页面上对不上题解的地方，别默认它对** —— 2026-11-07 那张 101 的页面上代码就用了 JavaScript 的 `//` 注释，Python 要用 `#`。**抄进 LeetCode 会直接报语法错。**

## 其他注意事项

- **需要联网**：这些页面都从 CDN 加载 Tailwind / 图标 / 字体。**断网打开会变成白底无样式**（按钮还能点，但很丑）。
- 页面里的代码是**那一题的参考解法**，不是你的答案。看着它 AC 不算数。
