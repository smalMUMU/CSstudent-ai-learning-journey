为什么递归比对是：check(a.left, b.right) 和 check(a.right, b.left)？

二叉树的镜像对称要求沿中轴对折后能够重合。因此：

外侧对齐 (Outer Pair):

a.left 与 b.right 比对。最左外沿对齐最右外沿。

内侧对齐 (Inner Pair):

a.right 与 b.left 比对。向中轴靠拢的两侧互相比较。

if not root: return True
def check(a, b):
if not a and not b:
return True // 均为空，镜像对称
if not a or not b:
return False // 一空一非空，结构不对称
if a.val != b.val:
return False // 值不相等，数值不对称
return check(a.left, b.right) and
       check(a.right, b.left)
return check(root.left, root.right)
