LeetCode 46. 全排列 (Permutations) 回溯算法 Backtracking

同步追踪：决策树生长与回退 · path 路径 · used 占用状态 · backtrack() 调用栈
1. 为什么不能只用嵌套 for 循环？

数组长度 n 是动态的，无法写死 n 层循环；回溯本质上是把“每层选一个数”写成递归，用调用栈自动管理任意深度的嵌套。

2. used 数组解决了什么问题？

全排列要求每个元素只能用一次。used[i] == True 表示下标 i 的元素已在当前 path 中，本层循环直接跳过，避免重复选取。

3. 为什么要 pop() 和重置 used[i] = False？

当一个分支走到底（res.append(path[:])）后，必须“撤销选择”恢复现场，父节点才能继续尝试下一个未用过的数字。
