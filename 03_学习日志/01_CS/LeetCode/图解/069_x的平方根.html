核心面试重点剖析：为什么最终返回 right，而不是 left？

1. 退出循环的状态

循环条件是 while left <= right。当循环结束时，必然满足：
left = right + 1 (即 right < left)。

2. 区间的不变量保证

在整个查找过程中，我们维护着：
所有已排除的左侧满足 k² ≤ x，所有已排除的右侧满足 k² > x。

3. 结论：向下取整刚好是 right

因此结束时，right² ≤ x < left²。right 恰好是平方不超过 x 的最大整数，也就是要求的向下取整平方根 ⌊√x⌋！
