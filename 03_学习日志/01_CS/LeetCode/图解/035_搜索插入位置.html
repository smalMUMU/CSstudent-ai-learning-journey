2     def searchInsert(self, nums: list[int], target: int) -> int:
3         left = 0
4         right = len(nums) - 1
5         while left <= right:
6             mid = (left + right) // 2
7             if nums[mid] > target:
8                 right = mid - 1
9             elif nums[mid] < target:
10                 left = mid + 1
11             else:
12                 return mid
13         return left
为什么最后返回 left？（循环不变量）

二分查找全过程中始终维持着一个极其优美的循环不变量 (Loop Invariant)：

1. 所有下标 < left 的元素都严格 < target
2. 所有下标 > right 的元素都严格 >= target

当循环结束退出时，必定满足 left = right + 1。 此时下标 left 刚好就是第一个大于等于 target 的位置，也就是 target 的天然插入点！

1. 题目要求本质

给定一个排序数组和一个目标值，在数组中找到目标值并返回其索引；如果目标值不存在于数组中，返回它将会被按顺序插入的位置。必须使用时间复杂度为 O(log n) 的算法。

2. 四种终态推演（为什么永远返回 left）

情景 A：目标在数组中
nums[mid] == target 直接在第 12 行返回 mid。
情景 B：目标比所有元素都小
right 一路缩小到 -1，left 维持 0。退出循环返回 left = 0（插入首位）。
情景 C：目标比所有元素都大
left 一路增大到 len(nums)，right 维持 n-1。退出循环返回 left = n（追加末尾）。
情景 D：目标在两个元素之间
最终搜索区间收缩到相邻两数，最后一步 left 跨过 right，left 恰好停在待插入索引。

3. 常见避坑与面试要点

  • 防溢出写法：在 Python 中整数不会溢出，但如果在 C++ / Java 中，建议写成 mid = left + (right - left) // 2，防止 left + right 超过整型最大值。
  • 循环条件：使用 left <= right 闭区间搜索。区间为空的条件是 left > right。每次排除 mid 后，新区间为 [left, mid-1] 或 [mid+1, right]，绝不漏掉任何元素。
