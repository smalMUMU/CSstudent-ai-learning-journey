核心图解：不盲目向后找，而是向“备忘录”回看
暴力双循环是“我拿着每个数，往后挨个找谁能凑成 target”（耗时 O(n²)）。 哈希表做法是：每走到一个数 x，立刻计算它需要的拼图碎片 need = target - x。如果这个碎片已经在字典 seen 登记过，说明两数成功会师！没找到就把自己登记进字典备查。

Hash Map / Dict 解法
1class Solution:
2  def twoSum(self, nums: list[int], target: int) -> list[int]:
3    seen = {}
4    for i, x in enumerate(nums):
5      need = target - x
6      if need in seen:
7        return [seen[need], i]
8      seen[x] = i

算法分析与对比

时间复杂度
O(N) 线性扫描
仅需遍历一次数组，哈希查找为 O(1)
空间复杂度
O(N) 空间换时间
哈希表最多存放 N 个元素的映射
为什么 Key 存数字，Value 存下标？

因为我们手头有需要的数值 need，题目要求最终返回的是下标。字典以元素值为键，让我们能以 O(1) 的超高速度根据数值直接取出其历史下标 seen[need]。
