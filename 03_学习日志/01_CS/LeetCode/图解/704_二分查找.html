二分查找核心考点精讲
为什么是 while left ≤ right 而不是 left < right？

本题采用的是经典左闭右闭区间 [left, right]。 因为两端都是闭合的，当 left == right 时，区间例如 [2, 2] 仍然合法且包含一个有效元素！如果使用 left < right，则在只剩最后一个元素时会提前跳出循环，导致最后一个元素被漏查。

💡 记忆法则：循环不变量原则——区间的定义决定了边界的处理方式。
为什么是 left = mid + 1 和 right = mid - 1？

因为在判断中，我们已经执行了 if nums[mid] == target。既然已经确定 nums[mid] ≠ target，那么 mid 这个位置就绝不可能再是目标值！

为了保证区间严格缩小并且防止死循环，新的搜索区间必须剔除掉 mid 本身，因此左移变为 right = mid - 1，右移变为 left = mid + 1。

整型溢出防护与 O(log n) 效率

在 Python 中整数精度是无限的，但如果在 C++ / Java 等强类型语言中，当 left + right 超过最大整型限制时会发生数值溢出。 最佳工业写法为： mid = left + (right - left) // 2

时间复杂度 O(log n)：每次比较都将待查区间缩减一半（$N \to N/2 \to N/4 \dots$），最多只需 $\lceil\log_2 n\rceil + 1$ 次比较即可确定结果。
