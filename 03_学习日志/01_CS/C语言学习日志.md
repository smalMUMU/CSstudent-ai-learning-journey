### 🛠️ 最小编译流程（照抄就行，这不属于"代写"）

```
gcc 文件名.c -o 程序名        # 编译：把源码变成 exe
.\程序名                      # 运行（PowerShell 下要有 .\）
gcc 文件名.c -o 程序名 -Wall  # 推荐：把警告全打开，很多坑在这里提前暴露
```

> ⚠️ 报错只读**第一条**；`-Wall` 一定要开——它能提前抓出"变量没初始化""少分号"这类错。

## 🧭 从 Python 迁到 C：我预判会遇到的三处（**踩到才算数**）

> 这三条不是知识点灌输，是给"分支与循环"阶段的预警。**真栽了才写进上面的高频坑表。**

1. **缩进 → 大括号 + 分号**：Python 靠缩进决定"谁属于谁"，C 靠 `{}`，缩进只是给人看的。**忘记大括号 + 悬挂 else** 是这一章最常见的错。
2. **`=` 与 `==`**：我在 Python 里两个方向都踩过（283 该赋值用了 `==`、657 该比较用了 `=`），C 不会报错救不了我。
3. **边界与 off-by-one**：`for (i = 0; i < n; i++)` 的 `i < n` 和我在 LeetCode 卡过三次的循环条件是**同一个问题**，换个语言会原样复发。
