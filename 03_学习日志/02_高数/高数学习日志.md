## ✍️ 2026-09-07 · Day 1 极限本质

**🎯 今天搞懂的一件事**：极限是"当 x 无法直接代入时，描述函数在附近趋近的那个确定值；它不要求函数真的到达那个点。"

### 1. 核心概念（我现在理解）
- 极限 = 函数"**趋近**"的那个**确定的值**；**趋近是过程，极限值是结果**（别把两者混了）。
- 它**不关心**函数在那个点**到底等于什么**（甚至可以不定义/有洞），只关心"**靠近时会怎样**"。
- 例：`lim (x²-1)/(x-1) = 2`，但 `x=1` 时是 0/0 没定义（**洞**），极限依然存在、等于 2。

### 2. 我的误区（这次的坑，务必记住）
- ❌ 一开始以为"**有洞 ⇒ 极限不存在**"——**反了**。
- ❌ 以为"极限只是趋近"是"还没定下来"——**错**，极限值本身就是**固定的数**（这里就是 2）。
- ✅ 纠正：**洞恰恰是"极限存在"最典型的例子**；极限 = 解决"那个值存在、但你到不了"的工具。

### 3. 我的复述一句话（写下来）
> "极限是当 x 无法直接代入时，描述函数在附近趋近的那个确定值；它不要求函数真的到达那个点。"

### 4. 联系 CS / 再往前
- **导数、积分底层都是"极限"**——这是为什么"极限"是整门微积分的地基。
- 明天 **Day 2 连续性** = 极限存在 **且** 极限 = f(1)。我这个函数 lim=2 但 f(1) 是洞 ⇒ **可去间断（不连续）**——这正是自测 Q7 栽的那一题。

## ✍️ 2026-09-09 · Day 2 连续性

**🎯 今天搞懂的一件事**：连续 = 极限存在 **且** 极限 = f(1)。只"能靠近"不算连续，还要"真的到"。

### 1. 核心概念（我现在理解）
- 连续 = 能"**一笔画**"顺滑走过那个点——不跳、不断、不掉坑。
- 在 x=a 处连续要**三者都成立**：① f(a) 有定义 ② lim 存在 ③ 二者**相等**。
- 一句话：**连续 = "极限值" 和 "函数值" 能接上。**
- 判断流程：① f(a)=? ② lim=? ③ 相等吗？（相等→连续；不等→间断）

### 2. 这次判断的题（三步走）
`f(x) = {x²−1, 当 x≠1 ;  3, 当 x=1 }` 在 x=1：
- ① f(1) = **3**（有定义）✅
- ② lim = **2**（存在）✅
- ③ 3 ≠ 2 → **不连续** ❌
- 类型：**可去间断**（因为极限存在，只是"函数值没接上"；若把 f(1) 改成 2，它就连贯了 → 所以叫"可去"，能修好）

### 3. 我的误区 / 自我纠正
- ❌（自测 Q7 的错）"连续 = 极限能求出来" —— 错。
- ✅ 现在：连续 = 极限存在 **且** 极限 = f(1)。

## ✍️ 2026-09-14 · Day 3 两个重要极限

**🎯 今天搞懂的一件事**：`lim_{x→0} sin(x)/x = 1` —— 本质是"小角度时 sin(x) ≈ x"，它把三角函数在 0 附近变成了直线。

### 1. 核心概念
- 第一个重要极限：`lim_{x→0} sin(x)/x = 1`（**x 必须用弧度**）。
- 意思：角度很小时，`sin(x)` 和 `x` 几乎一样大 → 工程里的「小角度近似」`sin(x) ≈ x`。
- 用法：把式子**凑成 `sin(□)/□` 的标准形**（分母必须和 sin 括号里一致）——**别再条件反射用洛必达**。

### 2. 今天做出来的题（全对 ✅）
| 题 | 结果 | 关键步骤 |
|---|---|---|
| `lim sin(3x)/x` | **3** | 拆成 `3·sin(3x)/(3x)` |
| `lim sin(5x)/sin(3x)` | **5/3** | 上下**同时**凑标准形 |
| `lim (1−cos x)/x²` | **1/2** | 用 `cos x = 1 − 2sin²(x/2)` 消掉 1 → `(1/2)·[sin(x/2)/(x/2)]²` ⭐分水岭题 |

### 3. 我的关键思路（值得记，这是真本事）
> 拿到题先想"**目标结构是什么**"：因为要用 `sin(□)/□ → 1`，所以必须先**消掉那个 +1/−1 的加减项**——配出来的结果**不可能带孤立的常数加减**。
> 这是**从"终点形状"倒推变形**，比瞎凑强得多。

### 4. 我还没讲清的点（陷阱题 → 已补）
- **为什么必须用弧度？** 换成度：`lim sin(θ°)/θ = π/180 ≈ 0.01745 ≠ 1`。
- 原因：**弧度的定义就是"角度的数值 = 弧长"**，所以 sin(x) 能直接和弧长 x 比、比值→1；用度则 1° = π/180 弧度，多出一个 **π/180** 系数。
- 所以"**=1 是弧度专有的**"——这也是为什么微积分**默认用弧度**（`(sin x)' = cos x` 也只在弧度下成立）。

### 5. 再往前
- 第二个重要极限：`lim_{x→∞}(1+1/x)^x = e` —— **e 就是从这里来的**（连接 T8 指数/对数）。
- 下一课 Day 4：**导数定义式 + 微分**（你已会算，重点补"定义/是什么"）。

## ✍️ 2026-09-16 · Day 4 导数定义式（+ 微分初步）

**🎯 今天搞懂的一件事**：导数公式不是天上掉的，它来自定义式 —— **平均变化率取极限 = 瞬时变化率 = 切线斜率**。

### 1. 核心概念：定义式怎么来的
```
第 1 步  取两点 a、x → 平均变化率 = [f(x)-f(a)]/(x-a)    （割线斜率）
第 2 步  让 x→a：割线转成切线，平均转成瞬时
第 3 步  取极限 → f'(a) = lim(x->a) [f(x)-f(a)]/(x-a)
```
- 等价写法：`f'(a) = lim(h->0) [f(a+h)-f(a)]/h`
  - **`h` 是什么？** `h = x − a`，就是把"**自变量之差 Δx**"起个名字叫 h（代入 `x = a+h` 即得）。
  - ⚠️ 我一开始把 `x->a` 版的格式硬套进 h 版，所以看不懂——**h 不是"没有减法"，h 本身就是那个减法的结果**。
- **各部分含义**：分子 = 函数值变化量(Δy)；分母 = 自变量变化量(Δx)；相除 = **变化率**；`lim` = 从"平均"升级成"瞬时"。
- **它天生是 0/0**（分子分母都 →0）→ 这就是"**为什么必须先学极限**"。

### 2. 我的误区（今天最大的坑）
- ❌ **一开始式子就列错了** —— 不知道"怎么把定义套进去"。
- ❌ 以为"用定义求"很难；其实卡点在**列式子**，不在计算。
- ✅ 纠正：**分子 = 函数值之差，分母 = 自变量之差；上下配对、同一个变量。**
- ✅ 常见错法：`[f(x)-f(a)]/x`（分母丢 `-a`）、`f(x)/(x-a)`（分子忘减 `f(a)`）、分子用 `h` 分母用 `x`（没对齐）。

### 3. 我今天独立做出来的
- `f(x)=x²` 在 `x=3`：`lim(x->3)(x²-9)/(x-3) = lim(x+3) = **6**` ✅
- `f(x)=x²` 在 `x=2`：`lim(x->2)(x²-4)/(x-2) = lim(x+2) = **4**` ✅（这次式子列对了）

### 4. 最大的收获（我自己说的）
> "我其实一直在想高中的导数公式怎么来的，我尝试推导过但是我推不出来，也就一直没理解，**直接背下来用了**。"

→ 今天终于摸到"公式的来源"。**高中那些公式，全都藏在定义式里。**

**为什么当年推不出来？（我自己的复盘）**
1. **工具不够**：学导数时还**没学二项式定理**，没法展开 `(x+h)ⁿ`；
2. **定义不熟**：不清楚 `h` 就是"自变量改变量 Δx"（格式混用导致看不懂）。
→ **不是脑子问题，是"工具 + 概念"两个缺口。现在两个都补上了。**

### 5. 微分（初步，待复习）
- **导数** `dy/dx = f'(x)`：一个**比值**（斜率）。
- **微分** `dy = f'(x)·dx`：一个**量**（Δy 的线性近似）。
- 一句话：**导数是"变化有多快"，微分是"变化了多少"。**

## ✍️ 2026-09-29 · Day 5 二阶导 = 加速度（+ 综合复盘）

**🎯 今天搞懂的一件事**：**求一次导 = 速度，求两次导 = 加速度。** `s''(t)` 是**加速度**——不是"时间"（自测答错），也不是"速度"。

### 1. 核心概念：那条链
```
位置 s(t) ──求1次导──► 速度 s'(t) ──求1次导──► 加速度 s''(t)
"你在哪"              "位置变多快"            "速度变多快"
```
- 实测：`s(t)=t³−6t²` → `s'(t)=3t²−12t`（**速度**）→ `s''(t)=6t−12`（**加速度**）
- 加速度为 0：`6t−12=0 → t=2` ✅
- 联系项目：电梯仿真里"启动/刹车"就是 `s''≠0`；匀速时 `s''=0`。

### 2. 我的误区（今天两个，都要钉死）
- ❌ **链条错位一格**：以为 `s'`=位移、`s''`=速度（各往下挪了一格）。
  - 根因（我自己说的）：**"拿物理公式套，看起来相似就直接代入，没想过实际意义"** —— 用"形状匹配"代替了"意义匹配"。
- ❌ **连续第三条件又写成"可以求导"**（**第 3 次出现！**）
  - ✅ 钉死：**连续 = "有三点"** ①有**点**(f(a) 存在) ②有**极限**(lim 存在) ③**两点对齐**(lim = f(a))。
  - "可导"是**另一个话题**、且更强：可导 ⇒ 连续，但连续 ⇏ 可导（绝对值函数在原点连续却不可导）。

### 3. 防坑动作（以后每次套公式前用）
> 先问："**这个记号求了几次导？**" 0次=位置 / 1次=速度 / 2次=加速度。

### 1. 「连续 ≠ 可导」终于钉死（**第 4 次**才治住！）
- 之前 **4 次**都把连续第三条写成"可以求导"（自测 Q7 / 09-16 / 09-29 / 09-30）。
- **治住的讲法**：
  > **连续 = "线不断"（能一笔画）｜ 可导 = "有切线"（不尖角）**
  > 连续三条件里**永远没有"可导"**；第三条永远是「**极限值 = 函数值**」。
- 实测反例 `y = |x|` 在 `x=0`：
  - 连续吗？**是** ——"图像没有断开的点" ✅
  - 可导吗？**不是** ——"图像是尖的，**导出来不具有唯一性**" ✅（**这个理由非常锋利**）
  - 精确版：左导数 = −1、右导数 = +1，**左右不一致** → 没有唯一切线 → 不可导。

### 2. 搞懂了 `d` 是什么（之前一直在用却不知道）
- `d` = "**一点点**"（来自 differential 微分）= **极小的改变量**。
- `dx` = x 的一点点改变；`dy` = y 的一点点改变；`dy/dx` = **两者之比 = 变化率 = 导数**。
- `d/dx` = "对 x 求导"这个**动作**（算符）。
- 对比：`Δx`（可大可小的改变量） vs `dx`（趋于 0 的极小量）。
- 生活版：`dx` = 时间走一滴答，`dy` = 车挪一点点，`dy/dx` = **车速**。

### 4. 加餐：T4 链式法则 = 反向传播（今天没顺延，做完了）
**🎯 搞懂的**：链式法则**为什么是相乘**。

- 题目：`y = (2x+1)³` → `dy/dx = 6(2x+1)²` ✅
- 拆两层验证：`u = 2x+1`、`y = u³`；`du/dx = 2`、`dy/du = 3u²`；相乘 = `6u² = 6(2x+1)²` ✅ 一致
- **"为什么相乘"的正解（我自己说出来的）**：
  > "因为系统**不是独立的，是相互依存的**，所以不是相加，而是几何倍数般的成长。"
  - 精确版：**两级串联（相互依存）** → 第一级把 x 的变化放大成 u 的变化，第二级再放大成 y 的变化 → **串联的倍数要连乘**。
  - 区分：**独立（并联）→ 相加；依存（串联）→ 相乘**。
- 推导（用 `d` 串）：`dy = (dy/du)·du`、`du = (du/dx)·dx` → `dy/dx = (dy/du)(du/dx)`
- 齿轮类比：A（x→u）放大 2 倍、B（u→y）放大 3 倍 → x→y 放大 6 倍 = 2×3
- **CS 身份**：这就是**反向传播** —— 网络从输出往输入逐层乘局部导数，是深度学习"学习"的引擎。
- ⚠️ 蝴蝶效应类比：**精神对**（小变化经链条放大），但精确含义是"混沌/敏感依赖"（不可预测）；链式法则是**确定、可精算**的倍数连乘，别当精确模型。
- 💡 又一处"**高中背了、老师没讲为什么**"：口诀"内导×外导"当时只用 Δ 描述、没讲细节 → 今天补上。

## ✍️ 2026-10-01 · T5 极值 & 梯度下降（国庆 · 第一次写 ML 代码）

**🎯 今天搞懂的**：用导数找最小值 —— "找极值 = 找 `f'(x) = 0`"；并**亲手写出、跑通了梯度下降**。

### 1. 核心概念
- **谷底是平的**：极小值处斜率 = 0 → 找极值 = 解 `f'(x) = 0`。
- **梯度下降**：不一定要解方程，可以"朝下坡走"：`x ← x − α·f'(x)`
  - 为什么"减"？`f'(x) > 0` 是上坡 → 往左（减）；`f'(x) < 0` 是下坡 → 往右。**永远朝下坡。**
  - `α` = 学习率（每步挪多大）。
- **CS 身份**：**这就是训练模型** —— 损失函数 = 要下的山，参数 = 位置 x，梯度下降 = 一步步调参让损失最小。

### 2. 我写的代码（`梯度下降练习.py`）
```python
def f(x):  return (x - 2) ** 2
def g(x):  return 2 * (x - 2)
alpha = 0.1
x = 0
for i in range(0, 51):
    x = x - alpha * g(x)
    print(x)
```
输出：`0.4 → 0.72 → 0.98 → 1.18 → … → 1.99997…` → **程序自己从 0 走到了 2** 🎉

### 3. 我踩的坑（都值得记）
| 坑 | 教训 |
|---|---|
| `return x` 写在**函数外** | `SyntaxError`；`return` 只能在函数内。而且这里要的是**打印** → 用 `print` |
| 把 `x` 同时当"位置"和"循环计数" | **一个变量不能干两件事**；循环圈数用独立变量 `i` |
| 漏了起点 `x = 0` | 用变量前必须先定义 |
| `if g(x) == 0:` 包住 `print` | **别用 `== 0` 判断浮点数**（几乎永不精确为 0）；打印要放在循环体里 |
| `while` + `for` 两层套着 | 会变**死循环**（内层跑完 i=50，外层判断 50<=50 永远为真）|

### 4. 彩蛋：学习率实验（我亲手跑的）
| α | 倍数 `(1−2α)` | 现象 | 我观察到的 |
|---|---|---|---|
| 0.1 | 0.8 | 慢慢收敛 | ✅ 逼近 2 |
| 0.5 | **0** | 一步到位 | ✅ 直接停在 2 |
| 1.0 | **−1** | 永久震荡 | ✅ 在 0 和 4 之间反复横跳 |
| 1.1 | −1.2 | 发散 | ✅ 越跑越大 |

**背后的漂亮结构**：令误差 `e = x − 2`，则 `e_new = (1 − 2α)·e`
→ **误差每步乘同一个数**：`|倍数| < 1` 收敛、`= 1` 震荡、`> 1` 爆炸。
→ 我观察到"**正负规律稳定**"，正因为 `α > 0.5` 时倍数为**负**，误差每步**变号**。

**为什么重要**：这正是 ML 里"**学习率是最重要超参数**"的真正原因 —— α 太大，损失就会震荡甚至炸成 NaN。

## ✍️ 2026-10-02 · T6 线性化 & 泰勒 / 牛顿法（⚠️ 在另一个对话框学的，此处补记）

**🎯 今天搞懂的**：**光滑函数在局部看起来像直线（或抛物线）** —— 所以能用直线"冒充"曲线，只要离得够近。

### 1. 核心公式
```
一阶:  f(x) ≈ f(a) + f'(a)·(x−a)                    ← 直线（切线）
二阶:  f(x) ≈ f(a) + f'(a)(x−a) + f''(a)(x−a)²/2    ← 抛物线
```
- **关键几何直觉**：这不是套公式，是**"用一条切线顶替曲线"**。

### 2. 动手：线性化 √x
`f(x) = √x`，`f'(x) = 1/(2√x)`；取 `a = 1` → `f'(1) = 0.5` → **√x ≈ 1 + 0.5(x−1)**

| 估计 | 结果 | 真值 | 误差 |
|---|---|---|---|
| √1.1（a=1，d=0.1） | **1.05** | 1.0488088 | **≈ 0.0012** |
| √2（a=1.5，d=0.5） | **1.4288690** | 1.4142136 | **≈ 0.0147** |

- 误差比 ≈ **12 倍**（距离走了 5 倍远）。
- **结论：误差随距离是"平方量级"，不是线性** —— 走得越远、错得越快。

### 3. 我的卡点（重要）
- ❌ 一开始把切线斜率当成了 **1**，算出 √1.1 ≈ 1.1（应为 1.05）。
- 原因：**没意识到 √x 的变化率在变小** —— 在 x=1 处每走 1 格，√x 只涨约 0.5，不是 1。
  （应该**先算 `f'(1)`**，而不是默认"斜率是 1"。）

### 4. 我自己的两个领悟
**① 线性近似的几何还原**
> `f'(a)` 是曲线在 a 点的斜率；`f(a) + f'(a)(x−a)` 就是"从 a 出发、顺着这个斜率走 (x−a) 那么远" —— **那就是切线**。所以不是套公式，是**用一条直线去顶替曲线**。

**② 二阶项存在的理由**
> 一阶导 = 变化的速度 → **二阶导 = 速度的变化速度 = "弯得有多厉害"**。
> 所以泰勒第二项就是**专门拿来补"弯"的那部分补偿**。
> **线性近似 = 忽略"弯"；加二阶项 = 把"弯"补回来一点；泰勒级数 = 一直补下去。**

### 5. 误差公式（把上面两个领悟合成一个）
```
误差 ≈ (1/2) · f''(a) · (x − a)²
```
**读法：误差 = ½ × 弯曲程度 × 距离²。** 越弯、越远，直线顶替得越差。

### 6. 学习方法反思（比内容更重要）
> **高中老师推导过泰勒公式，但记不住；这次算错了一次，反而记得很深。**
> 原因：高中那次是"知道怎么做"，没有"不知道会怎样"的痛，公式是空壳；
> **这次是撞了墙再回头 —— 这条链接是自己搭的，所以挂住了。**
> **可复用方法：学新公式先自己猜一个版本（哪怕错），再去验证。算错的那一下就是链接的起点。**

> ⚠️ **实验严谨性（补记时补上的）**：上面"12 倍"里 **`a` 也变了**（`f''` 从 −0.25 变到 −0.136），混进了两个效应。
> **更干净的做法：固定 a、只改距离** —— 如 a=1，d=0.1 vs d=0.5，误差应差 **25 倍（=5²）**。

### 8. 牛顿法：跑通结果与"平方收敛"的实测

**代码输出**（`x ← x − (x²−2)/(2x)`，从 x=1 出发 5 次）：
```
1.5
1.4166666666666667
1.4142156862745099
1.4142135623746899
1.4142135623730951      ← √2 满精度
```

**误差表（"平方收敛"的现场证据）**：
| 步 | x | 误差 | 正确位数 |
|---|---|---|---|
| 1 | 1.5 | 0.086 | ~0 |
| 2 | 1.4167 | 2.4×10⁻³ | ~2 |
| 3 | 1.414216 | 2.1×10⁻⁶ | ~6 |
| 4 | 1.4142135624 | 1.6×10⁻¹² | ~12 |
| 5 | 1.41421356237 | ≈ 0 | 满精度 |

→ **误差 ≈ 上一步误差的平方；正确位数每步几乎翻倍**（0 → 2 → 6 → 12）= "**平方收敛**"。
→ **第 4 步就到位**（对比：梯度下降跑了 **50 步**）。

### 9. 牛顿法的"意思"（原来只看公式，不懂意义）
> **站在当前点，用切线顶替曲线，把切线与 x 轴的交点当作下一站，反复逼近零点。**

- 这就是 T6 **"线性化"的直接应用**（用切线冒充曲线）。
- 公式来源：切线 `y − f(x) = f'(x)(X − x)`，令 `y = 0` → `X = x − f(x)/f'(x)`。
- 直觉读法：**该走多远 = 高度 ÷ 斜率 = `f(x)/f'(x)`**。
  - 斜率越陡 → 走越少就到 x 轴；越平 → 走越远。

### 10. 两个"逼近法"的对比（我自己串起来的）
| | **梯度下降**(T5) | **牛顿法**(T6) |
|---|---|---|
| 都在干嘛 | **反复逼近** | **反复逼近** |
| 找什么 | **谷底**（极值） | **零点**（`f=0`） |
| 停在 | `f' = 0` | `f = 0` |
| 用哪些信息 | 一阶导 `f'` | 一阶导 **+ 二阶导 `f''`** |
| 步长 | **自己设 α** | **自动算出**（高度÷斜率）→ **不需要学习率** |
| 速度 | 慢（50 步） | 快（4 步） |

**打通点**："找 `f` 的极值" = "找 `f'` 的零点" → 所以能对 `f'` 用牛顿法做优化（**二阶方法**）。

**彩蛋答案**：牛顿法这么快，**为什么深度学习不用它？**
→ 它需要 `f''`；几亿参数时 `f''` 是"几亿 × 几亿"的矩阵（Hessian），**存不下也算不动**；
→ 梯度下降只要一阶导，便宜得多。**"快"和"能用"是两回事。**

### 11. 编程：把「循环变量」这个坑彻底填平（第 2 次踩 → 已懂）
- ❌ 错误写法 `for x in range(1,6)`：`range` 每轮**强行重置 x** → 上一轮成果被扔 → 根本不迭代
  （实际输出 `1.5, 1.5, 1.833, 2.25, 2.7`，完全不收敛）。
- ✅ **正确理解**：
  > **循环只负责"重复"；`x` 的变化全部来自你自己写的那行赋值。**
  > 每轮开始时只有 `for` 后面的变量（`i`）被重新赋值，块内其他变量**保留上一轮的值** → 这才叫"迭代"。
- ✅ **验证过的预测题**：删掉赋值行、只留 `print(x)` → 打印 5 个 `1`（**答对 B = 真懂**）。
- 📌 **口诀**：看到 `range(...)`，里面的变量就是**计数器**，只能叫 `i`，**绝不能叫你要算的那个东西**。
