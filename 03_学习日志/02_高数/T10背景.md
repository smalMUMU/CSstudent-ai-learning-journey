## 零、总览：这件事的一句话

> **给一堆数据点，让计算机自己找出一条"最贴合"的直线。**

- 我们不给它公式，只给它数据；
- 它靠"猜 → 看看差多少 → 调整"反复迭代，最后找到那条线；
- **这个"反复调整"的过程，就叫「训练」**。

---

## 一、问题定义

### 1. 我们要找的"直线"

直线的一般形式：
```
y = w * x + b
```
- **`w`** = 斜率（x 每增加 1，y 增加多少）
- **`b`** = 截距（x = 0 时，y 是多少）
- **`x`、`y`** 是已知的数据，**`w`、`b` 是我们要求的东西**

> 换个说法：**`w` 和 `b` 就是"模型"**。训练的目的，就是找出最合适的 `w` 和 `b`。

### 2. 我们的数据

```
xs = [0, 1, 2, 3, 4, 5, 6, 7]
ys = [2, 5, 8, 11, 14, 17, 20, 23]
```

| i | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|---|
| **x** | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
| **y** | 2 | 5 | 8 | 11 | 14 | 17 | 20 | 23 |

**这组数据其实是按 `y = 3x + 2` 造出来的**（所以"标准答案"是 `w = 3`、`b = 2`）。
⚠️ 但程序**不知道**这一点 —— 它只知道这 8 个点，要靠梯度下降**自己把 3 和 2 猜出来**。

## 二、定义"拟合得好不好" —— 损失函数

### 1. 对每个点，先算"预测值"和"误差"

假设当前的 `w`、`b` 是任意两个数（一开始我们不知道，就随便猜，比如 `w=0`、`b=0`）。

对第 `i` 个点：
```
预测值 ŷᵢ = w * xᵢ + b
误差    = yᵢ - ŷᵢ          ←  真实值 减 预测值
```

**举例**：设 `w=0, b=0`，看第 1 个点（`x=1, y=5`）：
```
预测值 = 0 * 1 + 0 = 0
误差   = 5 - 0 = 5          ← 差了 5，说明预测得太小
```

### 2. 把误差"平方"，再全部加起来 → 损失 L

```
L(w, b) = Σ ( yᵢ - (w * xᵢ + b) )²
```

**( )² 是"平方"。求和符号 Σ 表示"把所有 8 个点加起来"。**

用我们这 8 个点展开，它长这样：
```
L = (2  - (w*0 + b))²
  + (5  - (w*1 + b))²
  + (8  - (w*2 + b))²
  + (11 - (w*3 + b))²
  + (14 - (w*4 + b))²
  + (17 - (w*5 + b))²
  + (20 - (w*6 + b))²
  + (23 - (w*7 + b))²
```

### 3. 为什么要"平方"？

| 原因 | 说明 |
|---|---|
| **① 让正负误差都变成"正的"** | 有的点预测偏高（误差负）有的偏低（误差正），直接加会**互相抵消**。平方后全变正，不会抵消。 |
| **② 让"错得多的点"更受重视** | 误差 3 平方变 9，误差 10 平方变 100 → **小错不太管，大错狠狠惩罚**。 |

> 💡 这个损失函数叫"**最小二乘法**"（least squares），是线性回归最经典的做法。

### 4. 两个关键性质

1. **`L` 越小 = 拟合得越好**（因为误差小了）；
2. **`L` 是 `w` 和 `b` 的函数**（不是 `x` 的函数！`x`、`y` 是已知的常数数据）。

> ⚠️ **这是最容易搞混的一点：**
> `L` 里虽然有 `x`、`y`，但它们是**已知的数据**（固定的）。
> **变化的是 `w` 和 `b`**。所以 `L` 是一个"关于 `w`、`b` 的函数"。

### 5. 于是问题变成了

> **找一组 `(w, b)`，让 `L(w, b)` 最小。**

这就是你 T5 学的"**找函数的最小值（谷底）**" —— 只是现在这个函数有**两个变量**。

---

## 三、怎么找最小值 → 梯度下降

### 1. 先复习一维的情况（你写过的）

一维：找 `f(x)` 的最小值。
```
x = x - alpha * f'(x)          ← 梯度下降
```
- `f'(x)` = 导数 = **坡度**，告诉你"往哪边走是下坡"；
- `alpha` = **学习率** = 每步迈多大；
- **减号** = "反着上坡走" = 往低处走；
- 反复走 → 走到 `f'(x) = 0` 的地方（谷底）停下。

### 2. 现在有两个变量，怎么办？

**原则：对每个变量，分别求它的偏导数（你在 T9 学过的）。**

> **T9 的口诀：对谁求导，另一个字母就当常数。**

所以要算两个导数：
| 导数 | 名字 | 问的问题 |
|---|---|---|
| `∂L/∂w` | 对 w 的梯度 | "把 w 调大一点，L 会变大还是变小？" |
| `∂L/∂b` | 对 b 的梯度 | "把 b 调大一点，L 会变大还是变小？" |

### 3. 更新规则（两个参数一起更新）

```
w = w - alpha * (∂L/∂w)
b = b - alpha * (∂L/∂b)
```

**每一轮：算出两个梯度，然后两个参数各自挪一步。**

## 四、梯度推导（详细版）—— 这一步最需要看懂

### 准备：要推的是

```
L(w, b) = Σ ( yᵢ - (w·xᵢ + b) )²
```

**每个点贡献一项**：`( yᵢ - (w·xᵢ + b) )²`
先看这一项，最后再把 8 项加起来（因为"和的导数 = 导数的和"）。

### ① 对 `w` 求偏导 → `∂L/∂w`

对一项 `( yᵢ - (w·xᵢ + b) )²` 求导，用**链式法则**（外层 × 内层）：

| 步骤 | 内容 |
|---|---|
| **外层** | `(  )²` 的导数 = `2 × (  )` → 得到 `2·( yᵢ - (w·xᵢ + b) )` |
| **内层** | `yᵢ - (w·xᵢ + b)` 对 `w` 求导：<br>· `yᵢ` 是常数 → 0<br>· `w·xᵢ` 对 w 求导 → **`xᵢ`**<br>· `b` 是常数 → 0<br>→ 结果是 **`-xᵢ`**（注意负号，因为括号里面是减号） |
| **相乘** | `2·( 误差 ) × (-xᵢ)` = **`-2 · (yᵢ - (w·xᵢ + b)) · xᵢ`** |

**8 项全加起来：**

$$ \frac{\partial L}{\partial w} = \sum_{i=0}^{7} -2 \cdot \Big(y_i - (w x_i + b)\Big) \cdot x_i $$

### ② 对 `b` 求偏导 → `∂L/∂b`

同样套路，**只是内层对 `b` 求导**：

| 步骤 | 内容 |
|---|---|
| **外层** | 同上面：`2 × ( 误差 )` |
| **内层** | `yᵢ - (w·xᵢ + b)` 对 **`b`** 求导：<br>· `yᵢ` 常数 → 0<br>· `w·xᵢ` 常数 → 0<br>· `b` 对 b 求导 → **`1`**<br>→ 结果是 **`-1`** |
| **相乘** | `2·( 误差 ) × (-1)` = **`-2 · (误差)`** |

**8 项全加起来：**

$$ \frac{\partial L}{\partial b} = \sum_{i=0}^{7} -2 \cdot \Big(y_i - (w x_i + b)\Big) $$

### ③ 两个梯度对比（关键理解点）

| | `∂L/∂w` | `∂L/∂b` |
|---|---|---|
| 内层对谁求导 | `w·xᵢ` → **`-xᵢ`** | `b` → **`-1`** |
| 结果 | `Σ -2·(误差)·xᵢ` | `Σ -2·(误差)` |
| 差在哪 | **多乘一个 `xᵢ`** | **不乘** |

> **为什么 `b` 的梯度不乘 x？**
> 因为 `b` 和 `x` **没有关系**（b 是"加在最后面的常数"，不管 x 是多少，b 都是加那么多）。
> **而对 `w` 求导时，`w` 是乘着 `x` 的，所以导数里带着 `x`。**

### ④ 一个直觉：梯度里的"投票"怎么理解

对第 `i` 个点，它对 `∂L/∂w` 的贡献是：

```
-2 · 误差 · xᵢ
```

**含义**：
- `误差` = 这个点错了多少；
- `xᵢ` = 这个点"**有资格评价 w 的程度**"（x 越大，这个点对"斜率"越敏感）；
- `-2` = 常数（来自平方求导）。

**特殊情况**：`x = 0` 的点贡献是 `0`。
> 因为 `x = 0` 时，不管 `w` 多大，`w × 0 = 0` —— **这个点完全没法告诉你斜率该多大**，所以它投 0 票。这是合理的。

## 五、完整流程（把上面所有东西串起来）

```
① 准备数据
   xs = [0..7]，ys = [2, 5, 8, ...]

② 初始化参数（随便猜）
   w = 0，b = 0

③ 开始迭代（比如 5000 次）：
   每轮做两件事：

   (a) 算两个梯度
       ∂L/∂w = Σ -2 · (yᵢ - (w·xᵢ + b)) · xᵢ
       ∂L/∂b = Σ -2 · (yᵢ - (w·xᵢ + b))

   (b) 各挪一步
       w = w - alpha · ∂L/∂w
       b = b - alpha · ∂L/∂b

④ 迭代结束后，打印 w、b
   应该接近 3 和 2
```

## 六、代码结构与对照

### 第 1 块：准备数据
```python
xs = list(range(8))            # [0,1,2,3,4,5,6,7]
ys = []
for x in xs:
    ys.append(3 * x + 2)       # 造数据 y = 3x + 2
```

### 第 2 块：w 的梯度函数
```python
def dl_dw(w, b):
    s = 0                                   # 累加器（用来把 8 个点加起来）
    for i in range(len(xs)):                # 遍历每个数据点
        s += -2 * (ys[i] - (w * xs[i] + b)) * xs[i]   # 加上这一点的贡献
    return s                                # 返回 ∂L/∂w
```

### 第 3 块：b 的梯度函数
```python
def dl_db(w, b):
    s = 0
    for i in range(len(xs)):
        s += -2 * (ys[i] - (w * xs[i] + b))           # 注意：这里不乘 x
    return s
```

### 第 4 块：训练循环
```python
alpha = 0.001                 # 学习率（每步迈多大）
w = 0
b = 0
for i in range(5000):         # 反复走 5000 次
    w = w - alpha * dl_dw(w, b)   # 先更新 w
    b = b - alpha * dl_db(w, b)   # 再更新 b

print(w, b)                   # 应该接近 3, 2
```

## 七、关键概念对照表（快速查）

| 东西 | 是什么 | 在代码里 |
|---|---|---|
| **`x`、`y`** | 已知数据（固定不动） | `xs`、`ys` |
| **`w`、`b`** | 要训练的**模型参数** | `w`、`b` 变量 |
| **预测值 `ŷ`** | `w·x + b` | `w * xs[i] + b` |
| **误差** | `y - ŷ` | `ys[i] - (w*xs[i] + b)` |
| **损失 `L`** | 所有误差的平方和（衡量多差） | **不用显式算**（只在纸上定义） |
| **梯度** | `L` 对参数的导数（方向） | `dl_dw`、`dl_db` 的返回值 |
| **`s`** | 梯度函数内部的累加器 | `s = 0` … `s +=` |
| **`alpha`** | 学习率（步幅） | `alpha` |
| **训练** | 反复"算梯度 → 挪一步" | `for` 循环 |
| **收敛** | 参数不再明显变化（梯度≈0） | 迭代结束时 w,b 稳定 |

## 八、常见坑（你踩过的都在这里）

| 坑 | 说明 |
|---|---|
| **累加器写成赋值** | `s = ...` 是覆盖；`s += ...` 才是累加。求和必须 `+=` |
| **循环变量混用** | `i` 用来数圈和下标；`w`、`b` 是被更新的值，别混 |
| **梯度函数只传一个参数** | 现在有两个参数，函数要写成 `dl_dw(w, b)` |
| **b 的梯度误乘 x** | `∂L/∂b` **不乘 x**（b 和 x 无关） |
| **alpha 太大** | 会震荡甚至发散（w 变成天文数字）→ 调小，如 0.0001 |
| **迭代次数太少** | 会没收敛到位 → 加大到 5000 |
| **括号** | 分母/分子里有 `+`/`-` 时必须加括号 |
| **浮点比较** | 别用 `==` 比浮点数，要用 `abs(...) < 小阈值` |

## 九、两个"验证"方法（训练完自己检验）

### ① 看参数
理论最优解（用最小二乘公式）：
```
w = Σ(x·y) / Σ(x²)  ← 如果 b 固定为 0
```
但**有 b 时**应该收敛到 `w=3, b=2`。

**你跑的如果是 `y = 3x+2` 的纯净数据，最后应该是 `w ≈ 3, b ≈ 2`。**

### ② 看梯度
在最优参数处，梯度应该 = 0：
```
dl_dw(3, 2) ≈ 0
dl_db(3, 2) ≈ 0
```
**"梯度为 0"就是"到达谷底"的检测信号。**

## 十二、一句话收尾

> **训练模型 = 定义"多差"（损失）→ 算"往哪调"（梯度）→ 反复调（梯度下降）→ 直到调不动（梯度=0）。**
