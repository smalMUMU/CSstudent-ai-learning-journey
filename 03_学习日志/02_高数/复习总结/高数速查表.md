---

## ① 一句话核心

**极限** = x 到不了那个点时,函数在附近"趋近的那个确定值"(与 f(a) 无关);
**连续** = 这个趋近值正好"等于"函数值;
**导数** = 平均变化率取极限 = 瞬时变化率 = 切线斜率;
**梯度下降** = 每步把"误差"乘一个固定倍数,朝下坡走到谷底(`f' = 0`);
**线性化/泰勒** = 光滑曲线在局部**可以用直线(或抛物线)顶替**,只要离得够近;
**积分** = 把"高 × 一点点宽"的小条**全部加起来**(面积/累积),和导数**互为逆**;
**梯度** = 坡度传感器,**永远指向"上升最陡"**;减梯度 = 走下降最快;
**训练** = 定义损失 → 算梯度 → 反复减梯度 → 梯度≈0 停下。

## ② 必记概念

| 概念 | 记住这一句 |
|---|---|
| **极限** | 描述"**趋近**"(过程)→ 结果是一个**确定的数** |
| **趋势 vs 点值** | lim 看**附近**;f(a) 看**那个点**;两者互不干涉 |
| **连续三条件** | ① f(a) **有定义** ② lim **存在** ③ **lim = f(a)** |
| **连续 vs 可导** | 连续 = **线不断**(能一笔画);可导 = **有切线**(不尖角)。**连续 ⇏ 可导**(如绝对值函数在原点连续却不可导) |
| **可去间断(洞)** | lim 存在,但 f(a) 没接上 → **改掉 f(a) 就能变连续** |
| **跳跃间断** | 左右极限**不相等** |
| **无穷间断** | 函数**冲向 ∞**(如 1/x 在 x=0) |
| **第一个重要极限** | `lim_{x→0} sin(x)/x = 1`(**必须弧度**) |
| **小角近似** | x 很小时 `sin(x) ≈ x` |
| **第二个重要极限** | `lim(1+1/x)^x = e ≈ 2.718`(**e 的出处**) |
| **导数定义式** | `f'(a) = lim(x→a) [f(x)−f(a)]/(x−a)`;等价 `lim(h→0) [f(a+h)−f(a)]/h` |
| **定义式怎么来** | 平均变化率(**割线**斜率)→ 取极限 → 瞬时变化率(**切线**斜率) |
| **它天生是 0/0** | 分子分母都 →0 → **这就是为什么必须先学极限** |
| **导数的意义** | 几何 = **切线斜率**;物理 = **瞬时速度 / 变化率** |
| **二阶导(物理链)** | `s` 位置 → 求1次导 `s'` **速度** → 求2次导 `s''` **加速度** |
| **幂函数公式来源** | `(xⁿ)' = n·xⁿ⁻¹` 来自**二项式定理**展开(只有带 1 个 h 的项活下来) |
| **微分** | `dy = f'(x)·dx`;**导数是比值(多快),微分是量(多少)** |
| **`d` 是什么** | `d` = "**一点点**"(微分)= 极小的改变量;`dx`/`dy` = x/y 的极小改变;`dy/dx` = 两者之比 = 导数;`d/dx` = "对 x 求导"的动作 |
| **极值在哪** | 极小值处 **`f'(x) = 0`**("**谷底是平的**")→ 找极值 = 解 `f'(x) = 0` |
| **梯度下降** | `x ← x − α·f'(x)`,就是"**朝下坡走**"。为什么"减"?`f' > 0` 上坡→往左;`f' < 0` 下坡→往右 |
| **学习率 α** | 每步迈多大。**不是越大越好**:太小→走得慢,太大→震荡甚至发散 |
| **误差结构(关键)** | 令误差 `e = x − 谷底`,则 `e_new = (1 − 2α)·e` → **每步误差乘同一个倍数** |
| **收敛判断** | 倍数绝对值 **< 1 收敛**、**= 1 震荡**、**> 1 发散** |
| **CS 对应** | 损失函数 = 要下的山;参数 = 位置 x;梯度下降 = **训练模型** |
| **线性化(一阶泰勒)** | `f(x) ≈ f(a) + f'(a)(x−a)` = **用切线顶替曲线**("离得够近"才准) |
| **二阶泰勒** | 再加 `f''(a)(x−a)²/2` —— 专门**补"弯"**的那一项 |
| **误差公式** | `误差 ≈ (1/2)·f''(a)·(x−a)²` → **越弯、越远,越不准**(距离是平方) |
| **牛顿法** | 求根:`x ← x − f(x)/f'(x)`,把切线一直用下去 → **收敛极快(平方收敛,约 4 步)** |
| **积分** | `∫ f(x)dx` = 把"高×一点点宽"的小条**全加起来**;`∫` = 拉长的 **S**(Sum);`dx` = 小条宽度 |
| **FTC(基本定理)** | `∫ₐᵇ f dx = F(b) − F(a)`;**导数与积分互为逆运算** |
| **定积分 vs 不定积分** | 有上下限 = **一个数**;无上下限 = **一个函数(+C)** |
| **被积函数 vs 原函数** | 围成面积的是**被积函数 f**;原函数只是 FTC 用的"尺子" |
| **数值积分误差** | 矩形法 ∝ **1/n**;梯形法 ∝ **1/n²**(梯形把"小三角"补上了 → 高一阶) |
| **e 的身份** | `(e^x)' = e^x`(**唯一导数等于自己**);一般 `(a^x)' = a^x·ln a` |
| **对数** | `(ln x)' = 1/x`;`ln` 与 `e^x` **互为逆** |
| **log n vs 2ⁿ** | `log n` 增长**极慢**(二分,好事);`2ⁿ` **指数爆炸**(坏事) |
| **偏导数** | **对谁求导,另一个字母当数字**;`3xy` 对 y 求导 = **`3x`**(不是 3y) |
| **梯度 ∇f** | 所有偏导打包成向量;**指向"上升最陡"**;负梯度 = 下降最快 |
| **线性回归** | 模型 `y = w·x + b`;损失 `L = Σ(y − w·x − b)²`(越小越贴合) |
| **两个梯度** | `∂L/∂w = Σ −2(y−wx−b)·x`(**乘 x**);`∂L/∂b = Σ −2(y−wx−b)`(**不乘 x**) |
| **训练** | `w ← w − α·∂L/∂w`、`b ← b − α·∂L/∂b`,反复迭代 |
| **训练何时停** | **不是"接近真值"**(真值未知),而是 **梯度 ≈ 0**(坡平了)或损失不再降 |

> 用法:① 凑标准形 `sin(□)/□`,别一上来就洛必达;② 套公式前先问"**求了几次导**"。

## ③ 概念之间的关系

```
      极限(整门课的地基)
        │  +"lim = f(a)"            │  +"割线→切线"
        ▼                            ▼
      连续性 ──► 一笔画             导数 ──► 切线斜率 / 瞬时变化率
        ▲                            │ 再求一次导
        │ 洞 = 可去间断              ▼
                                  二阶导 s''(t) = 加速度

  sin(x)/x → 1 ──► sin(x) ≈ x   ※必须弧度
                    ※"0 附近曲线变直线" ──► 这就是导数的思想
```

- **极限 → 连续**:连续 = 极限存在 **且** 相等。
- **极限 → 导数**:导数就是一个 **0/0 型极限**;没有极限就没有导数。
- **导数 → 二阶导**:再求一次导;物理上就是"速度 → 加速度"。
- **积分** 也建立在极限上(以后学)。
- **导数 → 极值**:极小值在 `f'(x) = 0`(谷底是平的)。
- **极值 → 梯度下降**:不用解方程,靠"**朝下坡走**"一步步逼近谷底 → **这就是训练模型**。
- **导数 → 线性化**:切线就是"**局部用直线冒充曲线**"。
- **线性化 → 牛顿法**:把切线一直用下去,就快速逼近方程的根。
- **极限 → 积分**:积分也是极限(无数小块求和的极限)。
- **导数 ↔ 积分**:**互逆**(FTC):位移求导 = 速度;速度积分 = 位移。
- **偏导 → 梯度**:梯度 = 所有偏导打包;**负梯度 = 下降最快**。
- **T1–T9 全部 → T10**:链式法则(推梯度)+ 偏导(分别求)+ 梯度下降(迭代)+ 找谷底 = **训练一个模型**。

## ④ 一个真实应用案例

**二分法求根(计算机怎么解方程)**
`f` 在 `[a,b]` **连续** 且 `f(a)`、`f(b)` **异号** → 中间**必有根**;计算机靠**二分逼近**求根。

> 同源:你电梯仿真里"位置/速度必须连续",而"启动/刹车"就是 `s'' ≠ 0`(有加速度)。

**训练模型(线性回归)**
数据 → 定义**损失**(衡量多差)→ 求**梯度** → 梯度下降迭代 → 参数收敛。
**这就是机器学习的"训练"内核。**

## ⑤ 最常见的误区

| ❌ 误区 | ✅ 真相 |
|---|---|
| 有洞 ⇒ 极限不存在 | **反了**:洞正是"极限存在"最典型的例子 |
| 连续 = 极限存在 | 漏了第三条:**lim 还得等于 f(a)** |
| **连续 = 可导** | **两码事!**连续="有三点";可导="有切线"。可导⇒连续,连续⇏可导(绝对值函数在原点连续却不可导) |
| "极限只是趋近" ⇒ 不是定值 | 极限值**是固定的数** |
| 用**度**也能 `sin x/x → 1` | **必须弧度**;用度 = **π/180** |
| 求极限先"代入" | 0/0 **不能代入**,只能说**趋近** |
| 见 sin 就洛必达 | 先**凑标准形** |
| **`s''(t)` 是速度 / 时间** | 是**加速度**!("求一次=速度,求两次=加速度") |
| **看着像就直接套** | 要"**数导数次数**",不是"看形状像不像" |
| **学习率越大学得越快** | **错**:太大 → 震荡或**发散**(α=1.1 就炸);太小 → 收敛慢 |
| **浮点数用 `== 0` 判断** | 几乎永不成立(浮点误差)→ 要用 `abs(...) < 小阈值` |
| **切线斜率随手当 1** | 必须先算 `f'(a)`(√x 在 a=1 处斜率是 **0.5**,不是 1) |
| **泰勒只是背公式** | 它是"**用切线/抛物线顶替曲线**";二阶项专门补偿"**弯**" |
| **定积分 = 不定积分** | **一个数 vs 一个函数(+C)**,完全不同 |
| **"原函数围成的面积"** | 围成面积的是**被积函数**;原函数只是**计算的尺子** |
| **积分是"近似值"** | **极限给的是精确值**;"近似"属于过程中的两个点 |
| **对 y 求导时 `3xy` 写成 `3y`** | 应该是 **`3x`**（x 当常数系数） |
| **梯度指向"上还是下"分不清** | 梯度**永远指"上"**（上升最陡）；要下降就**取负** |
| **`∂L/∂b` 也乘了 x** | **不乘**！b 和 x 无关，内层对 b 求导 = `−1` |
| **训练结束 = 接近真值** | 真值未知 → 看 **梯度 ≈ 0**（坡平了），不是看答案 |

**答案**
1. **4**(约成 `x+2`)
2. **不连续** —— lim=2 但 f(1)=3,**没接上**(可去间断)
3. **7**(拆成 `7·sin(7x)/(7x)`)
4. **弧度**;换度 = **π/180 ≈ 0.01745**
5. `f'(a) = lim(x→a) [f(x)−f(a)]/(x−a)`

9. 因为 `f'(x) > 0` 表示**上坡**(往右越高)→ 要下坡就得**往左(减)**;`f' < 0` 时减负数 = 往右。**总之永远朝下坡走**

13. `x ← x − (x²−2)/(2x)`;快是因为它用了**二阶信息(曲线的弯)**,**平方收敛**(约 4 步到 √2)
14. **4**（面积：三角形 ½·2·4）
15. **位移求导 = 速度；速度积分 = 位移** —— 一来一回走回原地
16. 定积分 = **一个数**；不定积分 = **一个函数（+C）**
17. **`e^x`**；因为 `(a^x)' = a^x·ln a`，只有 `ln e = 1` 时导数才等于自己
18. 二分 **20 步**；线性最坏 **约 100 万步**（差约 5 万倍）
19. **`3x + 2y`**（对 y 求导时 x 当常数）

21. `L = Σ(y − w·x − b)²`
22. `∂L/∂w` **乘 x**；`∂L/∂b` **不乘 x**（b 和 x 无关）
23. **梯度 ≈ 0**（坡平了）或损失不再下降 —— 不是"接近真值"
