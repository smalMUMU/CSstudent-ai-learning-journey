---

## ① 一句话核心

**极限 = x 到不了那个点时,函数在附近"趋近的那个确定值"(与 f(a) 无关);**
**连续 = 这个趋近值正好"等于"函数值。**

---

## ② 必记概念

| 概念 | 记住这一句 |
|---|---|
| **极限** | 描述"**趋近**"(过程)→ 结果是一个**确定的数** |
| **趋势 vs 点值** | lim 看**附近**;f(a) 看**那个点**;两者互不干涉 |
| **连续三条件** | ① f(a) **有定义** ② lim **存在** ③ **lim = f(a)** |
| **可去间断(洞)** | lim 存在,但 f(a) 没接上 → **改掉 f(a) 就能变连续** |
| **跳跃间断** | 左右极限**不相等**(跳一步) |
| **无穷间断** | 函数**冲向 ∞**(如 1/x 在 x=0) |
| **第一个重要极限** | `lim_{x→0} sin(x)/x = 1`(**必须弧度**) |
| **小角近似** | x 很小时 `sin(x) ≈ x` —— 工程里天天用 |
| **第二个重要极限** | `lim(1+1/x)^x = e ≈ 2.718`(**e 的出处**) |

> 用法:**凑标准形** `sin(□)/□`(分母 = sin 括号里的东西),**别一上来就洛必达**。

---

## ③ 概念之间的关系(一张图)

```
              极限(整门课的地基)
                │  再加上"lim = f(a)"
                ▼
              连续性 ──► 一笔画:不跳、不断、不掉坑
                ▲
                │  洞 = "极限在,点没对上" = 可去间断

   sin(x)/x → 1 ──► sin(x) ≈ x(小角近似)
     ※必须弧度         ※= "0 附近曲线变直线" ──► 未来的导数/线性化
```

- **极限 → 连续**:连续 = 极限存在 **且** 相等。
- **导数、积分底层也全是极限** —— 所以极限是地基。
- **弧度** 是 `=1` 的**前提**:弧度让"角度的数值 = 弧长"。

---

## ④ 一个真实应用案例

**二分法求根(计算机怎么解方程)**
若 `f` 在 `[a,b]` **连续** 且 `f(a)`、`f(b)` **异号** → 中间**必有根**。
计算机就靠它不断**二分逼近**求根 —— **"连续性"是算法能成立的前提。**

> 同类:你电梯仿真里"位置/速度必须连续",否则会瞬变、物理不真实。

---

## ⑤ 最常见的 6 个误区

| ❌ 误区 | ✅ 真相 |
|---|---|
| 有洞 ⇒ 极限不存在 | **反了**:洞正是"极限存在"最典型的例子 |
| 连续 = 极限存在 | 漏了第三条:**lim 还得等于 f(a)** |
| "极限只是趋近" ⇒ 不是定值 | 极限值**是固定的数**(比如 2) |
| 用**度**也能 `sin x/x → 1` | **必须弧度**;用度 = **π/180** |
| 求极限先"代入" | 0/0 **不能代入**,只能说**趋近** |
| 见 sin 就洛必达 | 先**凑标准形** `sin(□)/□` |

## ⑦ 5 道快速自测(先答,再对答案)

1. `lim_{x→0} (x²−4)/(x−2) = ?`
2. `f(x) = { x²−1 (x≠1) ; 3 (x=1) }` 在 x=1 连续吗?一句话理由。
3. `lim_{x→0} sin(7x)/x = ?`
4. `sin(x)/x → 1` 要求什么单位?换成"度"是多少?
5. `lim_{x→0} (1 − cos x)/x² = ?`

**答案**
1. **4**(约成 `x+2`)
2. **不连续** —— lim=2 但 f(1)=3,**没接上**(可去间断)
3. **7**(拆成 `7·sin(7x)/(7x)`)
4. **弧度**;换度 = **π/180 ≈ 0.01745**
5. **1/2** —— `cos x = 1−2sin²(x/2)` → `(1/2)·[sin(x/2)/(x/2)]²`
