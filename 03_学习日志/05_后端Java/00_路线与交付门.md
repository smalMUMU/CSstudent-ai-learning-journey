## 🪜 路线（课程是材料，交付门是主干）

> 左边一律照牛肉的**范围裁剪**执行——**他标了"只听部分"的地方，一定要真的只听那部分**，否则时间账会崩（总耗时 ≈ 视频时长 × 2）。

| 段 | 课程（黑马） | 范围裁剪（**照这个砍**） | 出口 |
|---|---|---|---|
| **0** | 工具链 | JDK 21 已装（`F:\Java\jdk-21`），PATH 待加 | **G0** |
| **1** | **JavaSE 上 + 下** | "看个过瘾、了解语法"。**难点（IO 流 / 多线程 / 网络编程 / 反射 / 动态代理）看不懂就跳过** | **G1** |
| **1.5** | （自己插的，3–5 天） | 手写 `HttpServer`。**只做 `/hello` + 一个 query 参数**，做完就走 | **G2** |
| **2** | **MySQL** | **只听**：数据库相关概念 → SQL 优化小结；进阶-锁-介绍 → InnoDB 引擎小结。**索引调优/集群以后再说** | **G3** |
| **3** | **JavaWeb** | "大致了解"，**重点看 Maven**（对后面帮助最大） | **G4** |
| **4** | **SSM** | "大致知道是啥玩意儿就行"，底层原理听不懂不硬求 | **G5** |
| **5** | **苍穹外卖** | **学多细学多细**（这条路线里唯一"不许偷懒"的一段） | **G6** |
| **6** | **Redis + 黑马点评** | 以项目维度学；**高级篇/原理篇先不听** | **G7** |
| **7** | **RabbitMQ**（+ Kafka 可选） | 能学多细学多细 | **G8** |

> 🚫 **阶段 4（SSM）之前不主动去啃 Spring 底层原理**——这跟"不听索引调优"是同一个原则：**先有网，再补洞。**
> 📌 **G1 故意不引入新算法**：词频统计你在 Python 里用 `Counter` 做过，换 Java 是**纯语法迁移**。别让"新语言 + 新算法"同时来。
