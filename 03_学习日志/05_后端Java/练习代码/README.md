# 📁 练习代码（后端 Java）

> **规矩**：**手敲，不复制粘贴**（打字量就是熟练度）；写错了改成对的也不能复制。
> **每个文件顶部写一行**：`// G? · 对应哪个交付物／复习到哪一条`。

---

## 📐 命名与目录约定

| 类型 | 文件名 | 例子 |
|---|---|---|
| 阶段练习 | `S{阶段}_{主题}.java` | `S1_word_count.java` |
| 交付物 | `G{编号}_{名字}.java` | `G0_Hello.java` |
| 冷写 | `冷写{轮次}_{名字}.java` | `冷写1_Hello.java` |
| 变体 | `变体{编号}_{名字}.java` | `变体2_前三个词.java` |

> ⚠️ **Java 的坑**：文件名必须和 `public class` 的类名一致（`Hello.java` ↔ `public class Hello`），大小写也要一致。

---

## 🧪 探针自检（跑之前先造小输入）

```
空输入 / 只有 1 个 / 边界值（0、负数、最大）/ 重复值
```

> **样例永远只给最舒服的那一组。**（这条在 C 课 3-2 上已经验证过：样例全过、隐藏点全错。）

## ⛏️ 编译与运行（PowerShell）

```powershell
javac Hello.java          # 编译 → Hello.class
java Hello                # 运行（不带 .class）
javac -encoding UTF-8 Hello.java   # 有中文时加
```

> ⚠️ **报错只读第一条**（栈顶那条 + 最靠上的"自己的类"那行）；后面全是连锁。
