## 九、Java ↔ Python：键盘录入（2026-11-07 记）

| | Python | Java |
|---|---|---|
| 导入 | `import math`（**模块**） | `import java.util.Scanner;`（**类**） |
| 能不能直接用 | 能，函数直接调 | **不行**，`Scanner` 要先 `new` 出对象 |
| 读一行 | `input()` | `sc.nextLine()` |
| 读一个数 | `int(input())`：**先读字符串，再转换** | `sc.nextInt()`：**直接给 `int`** |
| 谁决定类型 | **我自己**（转换函数） | **方法名**（`nextInt` / `nextDouble` / `next`） |
| 提示语怎么写 | `input("请输入：")` 一个参数搞定 | Scanner **没有提示参数**，得自己先 `print` |
| 读失败 | `ValueError` | `InputMismatchException` |
| 分隔规则 | **按行** | `nextInt()` **按空白**（空格/换行都算）；`nextLine()` 才按行 |

> ⭐ **一句话带走**：**Python 的 `input()` 只给你字符串，转不转是你的事；Java 的 `nextInt()` 说好了给 `int`，给不出来就直接炸。**
> ⚠️ **两个坑的根在这里**：① `nextInt()` 按空白、`nextLine()` 按行 ⇒ 混用会出现"残留换行被读走"；② 提示语要用 `print`（不换行）而不是 `println`（换行后光标跑了）。

## 十、Scanner 强化卡（2026-11-09 补 · 我自己提出"不熟悉"）

### 固定三步（背下来）
```java
import java.util.Scanner;                 // ① 类的外面、最上面
Scanner sc = new Scanner(System.in);      // ② 创建对象，告诉它从键盘读
int n = sc.nextInt();                     // ③ 读 + 必须用变量接住
```

### 读什么用什么方法
| 要读的东西 | 方法 | 分隔方式 |
|---|---|---|
| 整数 | `nextInt()` | 按空白（空格/回车都算） |
| 小数 | `nextDouble()` | 按空白 |
| 一个单词（遇空格停） | `next()` | 按空白 |
| **一整行（含空格）** | `nextLine()` | **读到回车为止** |
| 真假 | `nextBoolean()` | 按空白 |

### 五个必须知道的点

1. **一个 Scanner 可以反复用**：`new` 一次，后面 `sc.nextInt()` 想调几次调几次。**别每读一个就 `new` 一个。**
2. **读出来必须接住**：`sc.nextInt();`（不赋值）= 读了就扔，等于没读。（我自己犯过：忘了用变量承接）
3. **`nextInt()` 后接 `nextLine()` 会读到空串** —— 因为 `nextInt()` 只吃掉数字，**回车还留在缓冲区**，`nextLine()` 一进去就撞上那个回车，读到 `""`。
   - 修法 A：中间多调一次 `sc.nextLine()` 把回车吃掉
   - 修法 B：全程用 `nextLine()` + `Integer.parseInt(...)` 自己转
4. **输入类型不对 → `InputMismatchException`**（要求数字却打了 `abc`），程序直接炸。
5. **提示语用 `print`**（不换行），结果用 `println`。**先提示、后读**，顺序别反。

## 十一、长度 / 大小到底写哪个（2026-11-11 补 · 我考砸的那一题）

| 类型 | 怎么写 | 是属性还是方法 | 例子 |
|---|---|---|---|
| **数组** `int[]` / `String[]` | `arr.length` | **属性**（不加括号） | `arr.length` → 5 |
| **String** | `s.length()` | **方法**（必须加括号） | `"hello".length()` → 5 |
| **集合** `List` / `Set` / `Map` | `list.size()` | **方法** | `list.size()` → 5 |
| **char** 单个字符 | 没有长度概念 | —— | —— |

> ⭐ **一句话记法**：**数组用 `length`（没括号），其他一律 `size()` / `length()`（有括号）。**
> ⚠️ 别提"创建"和"取长度"混在一起：`new int[50]` 是**创建**，`arr.length` 才是**取长度**。
