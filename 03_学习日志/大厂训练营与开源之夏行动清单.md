# 大厂训练营 / 青训营 / 开源之夏 行动清单

> 目标：给准大一（内江师范学院 · 双非 CS）一份"能进得了、学得到、写进简历"的营/项目申报手册。
> 结论先行：**双非能进，学校基本不卡——筛选看的是申请材料、基础、主动性，不是院校背景。** 关键是选对类型、准备好材料、报名要早。

---

## 一、先分清两类（别选错）

| 类型 | 例子 | 学校背景影响 | 适合我？ |
|---|---|---|---|
| **选拔型技术营 / 青训营**（要想的） | 字节青训营、掘金×青训营×豆包MarsCode、公司暑期实训营、公益程序训练营 | 基本不影响，看申请/笔试/项目 | ✅ 主战场 |
| **科研向 / 内推型暑期营** | 部分"研究型大学联盟"C9 定向营、导师内推科研营 | 有一定影响，常向顶尖高校倾斜 | ⚠️ 别耗精力 |

## 二、推荐目标清单（按开放度 / 性价比排序）

### 1. 开源之夏（OSPP）—— 双非最友好
- **完全学校无关**：任何学生都能参与，按你申请/负责的开源课题评选。
- 适合：给真实开源项目**写功能、修 bug、提 PR**，成果直接挂在 GitHub。
- 时间：每年初春发布课题、学生报名（约 3-6 月），暑期开发。
- 参考：[OSPP 学生指南](https://blog.summer-ospp.ac.cn/help/student%20guide)

### 2. 字节青训营 / 掘金×青训营×豆包 MarsCode
- 面向在校学生，公开报名，靠**申请 + 笔试/评测**筛选，不看学校。
- 价值：能学到真实技术栈、有项目成果、有证书，部分青训营与实习/招聘挂钩。
- 参考：[掘金×青训营×豆包MarsCode 招募](https://www.cnblogs.com/asandstar/p/18438072)、[青训营第一视角](https://segmentfault.com/a/1190000041169108)

### 3. 公司自办暑期实训营（如七牛云等）
- 企业招募，开放报名，能接触真实业务，通常不卡学历。
- 参考：[七牛云暑期实训营招募](https://www.sohu.com/a/1032048021_121124209)

### 4. 公益 / 院校程序训练营
- 很多院校/组织办"公益程序设计训练营"，开放、免费、重基础。
- 例：[河北大学寒假程序设计公益训练营](https://cxcy.hbu.cn/hdzhjycy/xwgg/tzgg/101762328593758.html)

## 三、申请材料清单（能让我从"普通双非"里被捞出来）

> 这些营筛选看"有没有真做过东西"。下面材料是真正的敲门砖，现在就整。

- [ ] **GitHub 做得像样**：每个仓库写清 `README.md`（干什么、怎么跑、技术栈、我解决了什么）。
- [ ] **至少 2–3 个能打的项目**，每个都要能"讲深"（架构设计、踩坑、决策取舍）。
- [ ] **个人简历/简介**：突出项目 + 竞赛/开源经历 + 主动性，弱化"学校"。
- [ ] **在线作品/部署链接**：能直接跑起来的 demo，比只放代码更有说服力。
- [ ] **基础功底**：数据结构、一种语言、Git/命令行/调试（笔试小测会考）。

## 四、我的三个项目怎么改成"能打的作品"

| 项目 | 现在的状态 | 升级方向（让它进简历） |
|---|---|---|
| **pi_ai（agent）** | 学习型复刻，到 M1（calc） | 让它**能读文件/改代码/跑命令**，做成每天真在用的助手；写清架构与"为什么这么设计" |
| **ad-purifier（浏览器扩展）** | 已能过滤广告 | 加了规则订阅 + 可视化统计面板；补上线/测试；讲清 MV3 与数据流 |
| **电梯仿真** | 物理建模 | 若走 AI/算法路线可做成可视化 + 演示页；说明建模与工程取舍 |

> 原则：**少而精，能做深、能讲清，比数量重要。** 每完成一个就 push + 更新 README。

## 五、报名时间线与关注渠道

- **时间**：这类营多在**春季（2–4 月）发布招募**，部分暑期前截止。**报名要早**，名额和筛选都卷，早报有优势。
- **渠道**：① 学校就业/教务通知 ② CS 学生群 / 学长老师 ③ 字节/腾讯/阿里等官方公众号 ④ 开源社区（OSPP、各大项目主页）。
- **内推比海投管用**：学长、老师、同校去过这些营的人——主动去问，**熟人提名命中率远高于海投**。

---

## 六、三条提醒

1. **防"付费包offer训练营"收割**：网上很多标榜"几千块保offer"的是营销。**优先官方 / 免费 / 大赛性质**的（字节青训营、开源之夏、公司自办营）。真凭实力进的营才值钱。
2. **广撒网，别只押一个**：开源之夏 + 1~2 个大厂青训营 + 本地实训营**同时报**，哪个进了都是赚。
3. **进营后"装作没学历"地拼**：营里看能力不看学校。表现好，**训练营可帮你续到实习 / 绿色通道**——这才是它对你最值钱的地方。

## 七、待办勾选清单

- [ ] 把 GitHub 三个项目各写一份清晰 README

- [ ] 春季（2–4 月）开始报名：开源之夏 + 字节青训营 + 本地实训营

- [ ] 随时准备一个能跑起来的作品链接
