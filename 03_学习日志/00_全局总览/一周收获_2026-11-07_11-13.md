### 1. Java 语法底座：从零到"能写能讲"（7 天 83 个练习文件）
- **范围**：变量 → 运算符 → 判断 → 循环 → 数组 → 方法，全部走完；进入综合练习。
- **能讲清的**（不只是跑通）：
  - **数组 = 栈存地址、堆存数据** ⇒ "改内容影响外面、改指向不影响"（11-11）
  - **方法三问**：干什么 / 需要什么 / 要不要结果 —— **你自己总结的，已进速查表**（11-11）
  - **值传递 / 栈帧**（11-12）；**重载只看参数列表**，不是看返回值（11-12）
  - `continue` 在 `for` 里**仍会执行 `i++`**（11-10）
- **踩坑收敛成类型**（这是最值钱的）：
  - 边界 `<` vs `<=`：`i*i < number` 漏 4/9、`j*j < i` 漏 121/169 —— **第三次**（11-10、11-13）
  - **错误分支没中止**（11-10、11-12 两次）
  - 多分号 `if (max < x);`、接收端漏 `[]`、用 `int` 返回 1/-1 当布尔
  - 整数截断 / 溢出静默回绕 / 二进制表示不了十进制小数（11-08）
- **主动做出的设计**：`getScores` 的"合法输入才 `i++`"、加密解密的拒绝采样、**解密靠"≤4 说明溢出过"逆向还原——自己推出来的**（11-13）。
