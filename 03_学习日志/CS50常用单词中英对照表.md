# CS50 常用单词中英对照表

> 用法：**不用背！** 遇到不认识的来查一下，见几次就熟了。CS50 全程翻来覆去就这些词，靠重复自然记住，不是靠"学英语"。
> 配套：`CS50x学习日志.md`（进度）｜这份是"查词用"。

---

## 一、Scratch 界面（Week 0 立刻要用）

| 英文 | 中文 | 说明 |
|---|---|---|
| sprite | 角色 | 舞台上的每个人物 / 东西 |
| stage | 舞台 | 右上角那个大画面 |
| backdrop | 背景 | 舞台的背景图 |
| script | 脚本 | 你拼出来的一串积木 = 一段程序 |
| costume | 造型 | 一个角色的不同样子 |
| sound | 声音 | 音效 / 音乐 |
| when green flag clicked | 当绿旗被点击 | 程序启动的开关 |
| repeat | 重复（固定次数） | 循环，做 N 次 |
| forever | 重复执行 / 一直 | 无限循环 |
| if … then | 如果……那么 | 条件判断 |
| move … steps | 移动……步 | 让角色走 |
| say … | 说…… | 让角色说话（气泡） |
| variable | 变量 | 存一个数字 / 值的盒子 |
| touching … | 碰到…… | 侦测是否碰到某物 |
| event | 事件 | 什么时候触发（点绿旗、按键…） |
| choose a sprite | 选择一个角色 | 加人物用的按钮 |

## 二、CS50 核心概念（全课程都会遇到）

| 英文 | 中文 | 一句话 |
|---|---|---|
| computer science | 计算机科学 | 关于"信息与计算"的学科 |
| binary | 二进制 | 只有 0 和 1 的数制 |
| bit | 位 | 一个 0 或一个 1 |
| byte | 字节 | 8 个 bit |
| algorithm | 算法 | 一步步解决问题的办法 |
| loop | 循环 | 重复做一件事 |
| condition | 条件 | 满足才执行的判断 |
| function | 函数 | 一段可重复调用的代码 |
| variable | 变量 | 存值的盒子 |
| string | 字符串 | 一串文字，如 "hello" |
| array | 数组 | 一排连续存的值 |
| memory | 内存 | 程序运行时存数据的地方 |
| pointer | 指针 | 存"地址"的变量（C 里） |
| stack | 栈 | 内存的一块，管函数调用 |
| heap | 堆 | 内存的另一块，动态分配 |
| compile | 编译 | 把代码翻译成机器能懂的 |
| source code | 源代码 | 你写的、人能读的代码 |
| machine code | 机器码 | 计算机真正执行的 0/1 |
| syntax | 语法 | 写代码的规则 |
| bug | 程序错误 | 代码里的错 |
| debug | 调试 | 找错、修错 |
| error | 报错 | 程序出错的提示 |
| complexity | 复杂度 | 算法快慢的衡量（Big-O） |

## 三、命令行 / 提交命令（Week 1 起）

| 词 / 命令 | 中文 | 干嘛 |
|---|---|---|
| terminal / command line | 终端 / 命令行 | 敲命令的黑框 |
| cs50.dev | 云代码空间 | 浏览器里写代码的地方 |
| check50 | （判分命令） | 自动判你的作业对不对 |
| submit50 | （提交命令） | 交作业 |
| style50 | （格式命令） | 检查代码格式 |
| run | 运行 | 让你的程序跑起来 |
| make | 构建 | 把 C 代码编译成程序 |
| expected | 期望（值） | 报错时说"本该是啥" |

> 💡 **背单词捷径**：这些词里 loop / function / variable / condition / memory / algorithm 等，很多就是**四级高频词**。你每天背 20 个四级单词时，顺带把这几个也划进去，两边互相喂，比单独背划算。
