## 🚦 三条规矩（沿用我自己的系统）

1. **一次只读一篇。** 过闸了才准开下一篇。（豆包/workbuddy/chatgpt 三个包也**别同时开**）
2. **不追求读完 PDF。** 正文通常只有 6–8 页、一半是图。Methods / Extended Data / Supplementary **第一遍一律跳过**，不心虚。
3. **AI 只当陪读，不当替读。** 我读、我写；卡住问"这句人话是什么意思 / 这个符号指什么"。**AI 不许替我总结全文、不许替我写笔记**（第 0 条）。

## 🚪 闸门：读完的标准（三件，缺一不算读完）

| # | 交什么 | 具体标准 |
|---|---|---|
| 1 | **三问自答** | ① 它解决什么问题？（具体到"输入什么、输出什么"）② 怎么解决的？（一条主线 + 关键机制）③ **它还不能证明什么？**（边界） |
| 2 | **一句话** | 压成一句能对不懂的人复述的话。**我自己的话，抄摘要不算。** |
| 3 | **费曼口述** | 合上 PDF，讲给"只会 Python、没碰过 LLM"的人听，3 分钟。**卡在哪 = 哪没懂。** |

> **判据（老规矩）**：隔 3 天不看，还能讲出三问 + 一句话 = 真读完；讲不出 = 只能说"我读过"。
