## 一、项目全貌（它到底做了什么）

一个 B站网页版广告过滤浏览器扩展（Chrome/Edge MV3）：

```
ad-purifier/
├── manifest.json        MV3 清单（声明权限）
├── background.js        后台引擎：订阅下载/解析/缓存 + DNR 动态规则同步（8785 字节）
├── filter-parser.js     EasyList 规则子集解析器（3713 字节）
├── content.js           DOM 隐藏引擎：组合选择器 + 例外规则 + 防抖扫描（4419 字节）★ 本篇重点
├── options.html/js      设置页：开关 + 规则编辑 + 订阅管理 + JSON 导入导出
├── popup.html/js        工具栏弹窗：快速开关
├── lists/
│   ├── bilibili.txt     B站选择器库（内置）
│   └── network.txt      网络广告规则（内置兜底）
└── README.md
```

两条主线：
1. **DOM 隐藏**（content.js）：把页面上的广告元素 `display:none` 藏起来
2. **请求拦截**（background.js + declarativeNetRequest）：在浏览器层面拦截广告请求

document.querySelectorAll("选择器").forEach(el => el.style.display = 'none')

### 代码逐块注释（对号入座）

```js
(() => {                    // 积木1：IIFE，隔离作用域
  "use strict";             // 严格模式

  const CONFIG_KEY = "config";          // 积木2：常量命名
  const hidden = new Set();             // 积木5：记录已隐藏元素（用于恢复）
  let combinedSelector = "";            // 合并后的 CSS 选择器字符串

  function siteMatches(domains) {       // 站点作用域匹配
    const host = location.hostname;     // 积木8：读当前网站域名
    return domains.some((d) => d === host || host.endsWith("." + d));
  }                                     // 精确匹配或子域匹配

  function combine(selectors) {         // 增量校验合并选择器
    const ok = [];
    const frag = document.createDocumentFragment();   // 积木8
    for (const s of selectors) {
      try { frag.querySelectorAll([...ok, s].join(",")); ok.push(s); }
      catch (e) { /* 无效选择器丢弃 */ }             // 积木15：单条坏规则不拖垮整体
    }
    return ok.join(",");
  }

  async function buildRules() {         // 积木14：异步读配置
    const [cfgData, data] = await Promise.all([       // 积木7+14
      chrome.storage.local.get(CONFIG_KEY),           // 积木10：扩展存储
      chrome.storage.local.get(FILTER_KEY),
    ]);
    // ... 组装：内置规则 + 订阅规则(按站点过滤) + 用户自定义 + 兜底选择器
    // 去重 new Set(sels)，截断 MAX_COSMETIC=4000 防卡顿
    // combinedSelector = enabled ? combine(uniq) : "";
  }

  function restore() {                  // 关闭开关时恢复显示
    for (const el of hidden) { el.style.removeProperty("display"); }
    hidden.clear();
  }

  function hide(el) {                   // 核心动作（心脏那一行的封装）
    if (exceptionSelector && el.matches(exceptionSelector)) return;  // 例外不藏
    hidden.add(el);
    el.style.setProperty("display", "none", "important");
  }

  function scan(root) {                 // 扫描：自身匹配 + 子孙匹配
    if (root.nodeType === Node.ELEMENT_NODE && root.matches(combinedSelector)) hide(root);
    root.querySelectorAll(combinedSelector).forEach(hide);
  }

  function scheduleScan() {             // 积木13：防抖——150ms 内多次触发只扫一次
    if (scanTimer) return;
    scanTimer = setTimeout(() => { scanTimer = null; scan(document); }, 150);
  }

  const observer = new MutationObserver(scheduleScan);   // 积木12：监听 DOM 变化
  // observe(document.documentElement, { childList: true, subtree: true })
  // → 页面动态插入的广告也会被发现

  // 启动流程：读配置 → 扫一遍 → 开监听
  // 配置变更时 chrome.storage.onChanged 触发重建规则
})();
```

## 三、学习积木（按依赖顺序的完整路线）

```
积木1 JavaScript 基础（你懂 Python，转换极快，1–2 周）
   const/let / 箭头函数 / 数组方法 map·filter·some·forEach / Set / 展开 ... / 解构

   querySelectorAll / matches / style / addEventListener / 事件
积木3 CSS 选择器语法
   #id / .class / [attr^=] / 组合选择器（bilibili.txt 里全是）
积木4 浏览器扩展骨架
   manifest.json / content script vs background script / chrome.storage
积木5 进阶（大一上→下）
   MutationObserver / 防抖 / async·await / Promise
```

**每个积木的验收标准：能不看资料写出来。** 特别是积木1（JS 基础），因为你会 Python，语法迁移很快，先把这层拿下，content.js 立刻能看懂一半。

## 四、四个动手里程碑（全部自己写，卡住再问 AI）

### 里程碑 A：最小扩展（本周可做，约 20 行）

- 涉及：manifest.json（1 个权限）+ content script（5 行）
- 验收：Chrome `chrome://extensions` → 开发者模式 → 加载已解压的扩展程序 → 生效

- 目标：加"开关"和"例外"——Set 记录藏过的元素，开关关闭恢复显示

- 目标：MutationObserver 自动扫描 + 150ms 防抖
- 验收：此时 content.js 能看懂 70%
