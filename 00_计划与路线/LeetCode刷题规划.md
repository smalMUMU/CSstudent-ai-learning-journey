## 2. 刷题原则（5 条，照做）

1. **按专题扎堆刷**（一周一个专题，别跳来跳去）
2. **先想后看**：独立想 15~30 分钟，卡住才看题解
3. **关掉重写**：看懂后**合上答案自己敲一遍**
4. **每道填日志**：卡点 + 收获（`01_CS/LeetCode刷题记录.md`）
5. **间隔复习**：每刷 5 道新题重做 1 道旧题；周日抽 2~3 道旧题限时重写

## 5. ✅ Python 刷题必备"零件"清单（卡住就翻这个）

> 你反复遇到"**知道思路但写不出**"，多半是缺这里的某个"零件"。用到就学，用两次就记住。

**列表**
- `a.append(x)` 尾部加 ｜ `a.pop()` 删尾部 ｜ `a.pop(i)` 删第 i 个
- `a[i]`、`a[-1]`（最后一个）、`a[1:-1]`（去头尾）
- `a[::-1]` 反转 ｜ `len(a)` 长度 ｜ `sum(a)` 求和

**字典 / 计数**
- `d = {}`、`d[k] = v`、`d.get(k)`（没有就返回 `None`）、`d.get(k, 0)`（没有就返回 `0`，**安全**）
- ⚠️ **`get` 有几种写法，别写混**：`get(k)` 一个参数 → 缺省返回 `None`；`get(k, 0)` 两个参数 → 缺省返回 `0`
- ⭐ **计数标准写法（最常用，背下来）**：`d[k] = d.get(k, 0) + 1`
  - **一行同时管两种情况**：键不在 → `0 + 1`（登记成 1）；键在 → `旧值 + 1`
- ⚠️ **`d[k] += 1` 在键不存在时会 `KeyError`** —— 因为 `+=` 要先把旧值读出来，读不到就崩。**必须先用 `.get` 给个兜底**
- ⭐ **"压根没有 或 已经用完"一次判断**：`if d.get(k, 0) <= 0:` —— 缺省 `0` 把"压根没有"和"用完变 0"一起抓了（383 赎金信用）
- ⭐ **查"在不在"用 `in`，别用 `.get`**：`if k in d:`。**`.get` 拿的是"值"**，值可能是 `0`/`False`/`None` 而被误判（1 两数之和在这栽过）
- `Counter(s)`（数每个字符出现几次，`from collections import Counter`）
- 遍历：`for k, v in d.items()`
- **键/值方向永远问两句**：**键 = 你手上拿着的那个东西；值 = 你想知道的那个答案**

**集合**
- `s = set()` 建空的 ⚠️ **`{}` 是空字典，不是空集合**
- `s.add(x)` 加 ｜ `x in s` 查（**O(1)**）｜ `set(a)` 把列表转成集合（**自动去重**）
- **集合运算**（结果仍是**集合**）：`a & b` 交集 ｜ `a | b` 并集 ｜ `a - b` 差集
  - 例：`{1,2} & {2,3}` → `{2}`；`{1,2} | {2,3}` → `{1,2,3}`；`{1,2} - {2,3}` → `{1}`
  - 方法写法：`a.intersection(b)` / `a.union(b)` / `a.difference(b)`
- **集合 → 列表**：`list(s)` —— 题目要 `List[int]` 时**必须转**，直接返回集合会报 `Type is not JSON serializable: set`
- **列表 vs 集合**：`x in list` 是 **O(n)**（挨个比）；`x in set` 是 **O(1)**（哈希表）
- 什么时候用哪个：**要"键→值对应"** → 字典；**只要"在不在"** → 集合（少存一半、语义更准）

**字符串**
- `s.split()` 切分 ｜ `"".join(a)` 拼接 ｜ `s[::-1]` 反转
- `s.strip()` / `s.lstrip("-")` 去掉首尾/左边的字符
- `s.isdigit()` / `s.isalpha()` ｜ ⭐ **`c.isalnum()`** —— 是不是**字母或数字**（清洗最常用）
- `s.lower()` / `s.upper()` 转小写/大写（**返回新串，不改原串**）
- `ord(ch)` 字符→码 ｜ `chr(n)` 码→字符
- ⚠️ **字符串不可变**：**没有 `remove`**、不能 `s[i] = x`；`+=` 的实质是 **`s = s + 新内容`（每次造一个新串）**
- ⭐⭐ **字符串清洗三件套（背下来）**：
  ```python
  clean = ""
  for c in s:
      if c.isalnum():          # ① 过滤：只要字母数字
          clean += c.lower()   # ② 变形：转小写   ③ 收集：接到末尾
  ```
  - 一行版：`clean = "".join(c.lower() for c in s if c.isalnum())`
- ⚠️ **清洗后字符串会变短** ⇒ 所有依赖 `len` 和下标的指针都要**跟着重算**（125 在这越界过）
- ⭐ **空串判回文不用特判**：`left=0, right=-1` 时 `0 < -1` 为假，循环不跑直接返回 `True`

**内置函数**
- `len` `max` `min` `sum` `abs` `sorted`
- `range(n)`、`range(1, n)`
- `enumerate(a)`（同时拿下标和值）
- `zip(a, b)`（并行遍历两个）

**推导式 / 生成器**
- `[x*2 for x in a]`、`[x for x in a if x > 0]`
- `all(...)` 全真才真 ｜ `any(...)` 有一个真就真

**类 / `self`**（做 303 这种"设计题"必用）
- **`self` = 这个对象的「地址条」**（不是一栋房子，只是指向它；传 `self` 不复制对象）
- `self.xxx = 值` → 往**这栋房子里叫 `xxx` 的格子**放东西；`self.xxx` → 取出来
- ⭐ **`self.xxx` 跟着对象一直活**（所有方法都能拿）；**裸名（局部变量）函数一结束就没了**
- ⭐ **判断：这份数据要不要跨方法用？** 要 → `self.xxx`；不要 → 裸名
- 方法的第一个参数必须是 `self` —— **调用时不用传**（`obj.sumRange(0,2)` 背后是 `sumRange(obj,0,2)`，Python 自动塞对象）
- ⚠️ **`obj` 和 `self` 是同一栋房子**：`obj.x` 与 `self.x` 是同一个东西，不是两份副本
- ⚠️ **同名遮蔽**：方法里写 `x = [0,0,0]`（**不加 `self`**）**不会**改 `self.x` —— 名字相同≠同一个东西。这是"改了却没生效"最常见的病因
- `__init__` 只跑 **1 次**（适合干重活/预处理）；被反复调用的方法必须轻 —— **这就是"设计题"要写成类的原因**
