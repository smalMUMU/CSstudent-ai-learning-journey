# LeetCode 刷题规划（C++ · 大一启动）

> 配合《AI时代路线调整版与自学主线.md》的「主轴：数据结构与算法」使用。
> 核心心法：**不是"刷了多少道"，而是"看到一类题能反应出套路"。**

---

## 0. 现状与前提

- 已有：Python 基础 + 「编程入门 50 题」（约 20 道已记录在 `01_CS/LeetCode刷题记录.md`）
- 已成型的学习法：**先想后看 → 关掉重写 → 填日志 → 间隔复习**
- 现在要学 **C++** → **刷题语言切到 C++**

---

## 1. 为什么用 C++ 刷题

1. **大厂笔试/面试主流语言**（很多岗位默认 C++/Java）。
2. **和学校的 C++ / 数据结构课接轨**（一举两得：练算法 + 练课程语言）。
3. **练算法 + 练语法，一次搞定**。

### ⚠️ 过渡技巧（很重要）
> **先用 C++ 重刷你已用 Python 做过的题**（如 27、283、26、66、1、58…）。
> 因为你**已经知道算法**，可以**专心练 C++ 语法**，避免"算法不会 + 语法不会"**双卡**。
> 等 C++ 手感够了，再上新题。

---

## 2. 刷题原则（5 条，照做）

1. **按专题扎堆刷**（一周一个专题，别跳来跳去）
2. **先想后看**：独立想 15~30 分钟，卡住才看题解
3. **关掉重写**：看懂后**合上答案自己敲一遍**
4. **每道填日志**：卡点 + 收获（`01_CS/LeetCode刷题记录.md`）
5. **间隔复习**：每刷 5 道新题重做 1 道旧题；周日抽 2~3 道旧题限时重写

## 4. 每周节奏（一周一个专题）

| 时间 | 做什么 |

| **周一~周三** | 专题新题：每天 **1~2 道**（先简单，后中等） |
| **周四~周五** | 专题补题 + **总结这个专题的"套路"**（写进日志） |

## 5. 配合 C++ 学习（边刷边补语法）

**不用先学完 C++ 再刷题**——**刷题就是最好的 C++ 练习课**。遇到不会的 C++ 语法就查/问，用几次就会了。

**刷题必备的 C++ 语法清单**（用到就学）：
- 基本：`#include <bits/stdc++.h>`、`using namespace std;`
- 容器：`vector`（`push_back`、`.size()`、`[]`）、`string`、`unordered_map`、`set`
- 循环：`for (int i = 0; i < n; i++)`、范围 `for (int x : nums)`
- 函数与引用：`int f(vector<int>& nums)`（`&` 传引用，避免拷贝）
- 常用：`sort(v.begin(), v.end())`、`reverse()`、`max/min`

**对照你熟悉的 Python**（就像当初 Python→JS 那样，转过去很快）：
| Python | C++ |
|---|---|
| `len(nums)` | `nums.size()` |
| `nums.append(x)` | `nums.push_back(x)` |
| `for x in nums` | `for (int x : nums)` |
| `nums[-1]` | `nums.back()` |
| `{}` 字典 | `unordered_map<int,int>` |

## 6. 阶段里程碑（自检）

- **大一上结束**：专题 1~5 过完（数组/双指针/哈希/前缀和/字符串）；**简单题不怵**；C++ 语法能应付基础题
- **大一下结束**：专题 6~9 过完（链表/栈队列/二叉树/排序二分）；开始碰**中等题**
- **大二上**：专题 10~11（递归回溯/DP）+ 冲中等题
- **大二下**：剑指 Offer / 热题 HOT 100（部分）
- **大三**：冲刺期，按目标公司刷高频题

---

## 7. 调整机制（每周日复盘时用）

- **进度慢了** → 专题多花一周，别硬赶
- **进度快了** → 直接进下一个专题
- **某类型总卡** → 回头把该专题的"复盘教训"重看一遍，再补 2 道
- **卡题超过 30 分钟** → 看题解 → 看懂 → **关掉重写**

## 8. 避坑清单

| ❌ 别做 | ✅ 要做 |
|---|---|
| 随机无序刷 | **按专题扎堆刷** |
| 只刷简单题求数量 | 简单题打底，逐步上**中等** |
| 攀比刷题量 | 比"能不能讲出套路" |
| 刷完就忘 | **填日志 + 间隔复习** |
| 先学完 C++ 再刷题 | **边刷边补语法** |
| 一上来刷 HOT 100 | 按上面的专题顺序来 |
