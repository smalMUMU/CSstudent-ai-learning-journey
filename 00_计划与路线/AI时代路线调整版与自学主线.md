# AI 时代路线调整版 + 自学主线（2026 · 大一启动）

> 背景：结合行业现实与我的实际情况（已有 agent / 浏览器扩展 / 电梯仿真项目、学习法已成、准大一）对四年路线做定向调整，并给出"现在 → 大一暑假"的聚焦主线。
> 与《大学四年学习路线.md》配合使用：那篇是「校招应试打法」，这篇是「AI 时代的差异化 + 主线取舍」。两篇一起看，缺一不可。

---

## 一、为什么要调（行业现实 → 对我意味着什么）

**行业现实（3 句）**
1. 软产业还在增：2025 我国软件业务收入 154831 亿元，同比 +13.2%，行业本身没萎缩。
2. 但岗位结构被 AI 重写：AI 辅助编程 + 低代码最先压缩的是**初级/重复编码**岗位；"会写 CRUD"已不再稀缺。
3. 缺口集中在**高端 / 复合 / 会驾驭 AI** 的人；薪资在"正常化"，不再是人人高薪神话。

**对我意味着（3 句）**
1. 我已经在正确的车道上：没去卷"纯 CRUD 打工"，而是直接上手 agent。**这条线要继续加码**，而不是按老计划把它归为"门槛高、别碰"。
2. 我最要防的不是"被 AI 取代"，而是把自己养成"**只会背八股 + 刷题 + 写增删改查**"的经典校招 profile——那是 AI 压缩最狠的。
3. 别把视线锁死在"互联网大厂"。AI 时代，**制造/金融/医疗等行业的数字化都在招"懂 AI 的软件人才"**，更不卡学历。

> 结论：走「**AI 工程化 / Agent + 系统基础**」这条差异化路，比跟着校招大纲卷八股更抗 AI、也更有辨识度。

老路线说"AI 方向门槛高，不建议零基础直接冲"——**已过时**。因为我现在：

## 四、自学主线（现在 → 大一暑假，把劲聚焦到一条上）

> 心法：**自学不"什么都学"，要一条主轴线 + 少量保底。** 你最大的敌人不是学不够，而是摊子太开、把劲散掉。

### 🎯 主轴（约 60%）：数据结构与算法 + CS50 讲透"计算机怎么工作"
- 所有方向的钥匙 + 实习/笔试门槛。按专题刷，每天 1–2 题 + **必须先想后看**。
- CS50 每周一讲慢跑，比任何速成课都划算。

### ⚙️ 副轴（约 30%）：把 pi_ai 做成"真在用的 agent"（差异化亮点）
- 从 M1（calc）→ **读文件 / 改代码 / 跑命令** → 变成每天写码真在用的助手。
- 推到 GitHub、写清 README、能深挖——这才是"能放简历"的标准。

### 🧱 保底（约 10%）：大一学好 C + Git / 命令行 / 调试到顺手
- 学 C 为理解底层（配 CSAPP），Git/命令行/调试是任何实习的基本功。

### ⏰ 每周节奏（国庆后学校稳定了再用）
| 时间 | 内容 |
|---|---|
| 周一~周三 | 数据结构算法专题 + 项目（pi_ai） |
| 周四~周五 | CS50 一讲 + 笔记 |
| 每天 | LeetCode 简单题 1 道（15–20 分钟） |
| 周末 | 自由折腾（折腾=最好的学习），或给开源项目提 PR |

## 五、大一暑假策略（替换"盲目找 3 个月公司实习"）

> 目标：**大一暑假攒出"可被证明的硬货"**，而不是一张"打杂实习证明"。三样大一就能做到：

1. **大厂给低年级办的暑期训练营 / 青训营**（开放报名、不卡学校，看申请/项目）
2. **给真实开源项目提 PR / 开源之夏（OSPP）**（完全学校无关）
3. **把自己一个项目做成"上线、真有人用"**（产品 + 工程，最能写进简历）

> 提醒：大一暑假去真实公司做 3 个月实习"有可能但多为小公司/内推/体验型"，别拿青春去撞低命中率；把这劲头放到上面三件硬货上回报更高。详见《大厂训练营与开源之夏行动清单.md》

## 六、当前窗口（报到 + 军训 + 开学前两周）做什么

- [ ] **高数 + 英语四级**（按《9月学习计划》，每天 45–60 分钟高数、20 个单词）

## 七、自检（每学期末打勾）

- 大一上结束：数据结构算法基础过一遍 + pi_ai 已能读文件/当助手；LeetCode 简单题不怵
- 大一下结束：有 1 个完整项目（能讲深）+ 1 项竞赛/开源经历；高数线代跟得上
- 大一暑假：参与训练营 / 开源项目 / 上线一个作品
- 大二上结束：四大件跟上课 + 全栈项目进行中；锁定主攻方向

> 一句话：**踏踏实实走「AI 工程化 + 系统基础」这条差异化路，把劲聚焦到"数据结构 + pi_ai"两个点上——大一上学期结束时，你的简历就已经拿得出手了。**
