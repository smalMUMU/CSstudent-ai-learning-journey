# 学习路线（量身定制版）

> 适用对象：准大一学生，有一点 Python 基础，刷过少量 LeetCode
> 配套资源：`开发协作约定.md`（每次开发先讲知识点）、`广告净化器-知识点清单.md`（项目知识清单）
> 核心理念：**你的项目就是你的教材，编程是"做"会的，不是"看"会的**

---

## 0. 先摆正心态

- 你现在的水平（Python 基础 + 一点 LeetCode）**已经超过多数大一新生的入学水平**，很多人入学时是零基础
- 你现在最大的短板不是"知识不够"，而是**没完整做完过一个东西**——这恰恰是接下来要补的
- 编程学习是**复利**：前几个月感觉慢，一旦过了拐点，进步会越来越快。别急。

---

## 1. 学习总原则（5 条）

1. **项目驱动，不要"学完再动手"** —— 先让东西跑起来，再回头补原理。完美主义是学习编程最大的敌人
2. **教材就是你自己的项目** —— `ad-purifier/` 里每个文件都是一节课，我们每次开发都按《开发协作约定》先讲知识点
3. **语言是工具，不是目的** —— 你会 Python 再学 JavaScript 会很快（见第 5 节速查表），大学里再学 C 也一样，语言都是相通的
4. **LeetCode 是健身，不是主餐** —— 每天少量保持手感可以，别把它当学习的全部
5. **一次只学一件事** —— 同时开 5 门课 = 一门都没学会

## 2. 三条主线

### 主线 A：语言能力（这个暑假）

| 阶段 | 内容 |
|---|---|
| 已完成 | Python 基础（变量/循环/函数/列表/字典） |
| 这个暑假 | ① 用 Python 把基础打牢：函数、类、异常、文件读写、模块（跟着小练习做，不追求全懂） ② **同时通过广告净化器项目学 JavaScript**（我来讲，Python→JS 桥接很快） |
| 大一后 | 语言不用再焦虑——课上要学 C 就学 C，原理相通 |

> 提示：两条线不冲突——项目用 JS，你日常练习用 Python 保持手感。

### 主线 B：计算机基础（细水长流）

| 时间 | 内容 |
|---|---|
| 现在可开始 | **CS50**（哈佛免费公开课，B站有中文字幕，约 10 周）——最推荐的基础课，讲"计算机到底是怎么工作的"，每周一讲即可 |
| 大一课上 | 数据结构与算法（**重点课**）、计算机组成原理、操作系统——跟着学校进度学，不用提前焦虑 |
| 项目里学 | 网络知识（DNS/HTTPS/同源）我们项目天然涉及，学过滤广告顺便就懂了 |

### 主线 C：项目实践（和我们一起）

- **第一课就是广告净化器**：读代码 → 改代码 → 加功能，每个功能 = 一次"小课"
- 每完成一步要会：**调试**（F12 开发者工具）、**查文档**（MDN/官方文档）、**搜问题**（怎么把问题描述清楚）
- 做完这个，可以考虑第二个小项目（比如：把规则数据做成可视化统计面板、或一个 Python 小工具）

## 5. Python → JavaScript 速查表（过一遍就知道 JS 不难）

| Python | JavaScript | 备注 |
|---|---|---|
| `print("hi")` | `console.log("hi")` | 打印输出 |
| 缩进表示代码块 | `{ }` 大括号 | 最大区别 |
| `a = 1` | `let a = 1` / `const a = 1` | const 是常量，推荐默认用 |
| `[1, 2, 3]` | `[1, 2, 3]` | 数组，一样 |
| `{"k": "v"}` | `{k: "v"}` | 字典→对象 |
| `def f(x): return x` | `function f(x) { return x; }` 或 `const f = (x) => x` | 函数，箭头函数更常用 |
| `for i in range(5)` | `for (let i = 0; i < 5; i++)` | 计数循环 |
| `for x in arr` | `for (const x of arr)` | 遍历数组 |
| `if x > 0: ... elif ... else:` | `if (x > 0) {...} else if {...} else {...}` | 条件 |
| `len(arr)` | `arr.length` | 长度 |
| `str(x)` / `f"{x}"` | `String(x)` / `` `${x}` `` | 转字符串/格式化 |
| `import math` | `import ... from ...` | 导入模块 |
| `True / False / None` | `true / false / null` | 注意大小写不同！ |
| `async def` + `await` | `async function` + `await` | 异步编程概念一样，JS 里是 Promise |

> 小知识：JS 里分号可加可不加，字符串单双引号都行——别纠结这些，纠结就是浪费时间。

## 6. 避坑清单

| ❌ 别做 | ✅ 要做 |
|---|---|
| 教程地狱（收藏一堆从不写） | 看一个教程就跟着写一个 |
| 买几千块的课 | 免费资源足够（CS50 + 官方文档 + 项目） |
| 同时学 5 种语言 | 主 Python，副 JS（项目用） |
| LeetCode 攀比刷题量 | 每天 1 道简单题，保持手感 |
| 追求"看懂" | 写出来才算会（费曼学习法：能讲给别人听） |
| 卡住 30 分钟就问 | 先自己搜/试 20 分钟，再问（问也是学习） |
| 只看不记 | 用自己的话写笔记（哪怕很乱） |
