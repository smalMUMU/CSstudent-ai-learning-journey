# 广告净化器 · 知识点清单

> 与《开发协作约定.md》配套：本清单列出该项目用到的全部知识点，
> 按 🔴必备 / 🟡建议 / 🟢可选 分级，供每次开发前确认掌握情况。

## 一、编程基础（🔴 必备）

| 知识点 | 一句话说明 | 在项目中的用途 |
|---|---|---|
| HTML / CSS 基础 | 网页的结构与样式 | 选项页、弹窗界面 |
| JavaScript 基础 | 变量、函数、对象、数组、循环 | 全部逻辑 |
| DOM 操作 | 增删改查页面元素 | content.js 隐藏广告元素 |
| 异步编程（Promise / async-await） | 处理"耗时"操作不阻塞 | 读配置、网络请求 |

## 二、数据与存储（🔴 必备）

| 知识点 | 一句话说明 | 在项目中的用途 |
|---|---|---|
| JSON | 键值对数据格式 | 配置保存、导入导出 |
| chrome.storage API | 扩展的本地存储 | 配置与规则数据持久化 |

## 三、浏览器扩展机制（🔴 必备）

| 知识点 | 一句话说明 | 在项目中的用途 |
|---|---|---|
| Manifest V3 | 扩展的"说明书"（清单文件） | manifest.json |
| Content Script（内容脚本） | 注入到网页里运行的脚本 | content.js |
| Service Worker（后台） | 扩展的后台常驻逻辑 | background.js |
| Popup / Options 页面 | 扩展自带的界面 | popup.html / options.html |
| 权限模型（permissions / host_permissions） | 声明扩展能做什么 | 请求拦截、订阅下载 |
| 消息传递（runtime.sendMessage） | 页面与后台通信 | 选项页触发规则更新 |

## 四、请求过滤（🟡 建议）

| 知识点 | 一句话说明 | 在项目中的用途 |
|---|---|---|
| declarativeNetRequest (DNR) | 声明式拦截网络请求 | background.js 拦截广告请求 |
| 过滤规则语法（\|\|domain^） | 广告规则的语言 | 网络规则文件 |

## 五、前端进阶（🟡 建议）

| 知识点 | 一句话说明 | 在项目中的用途 |
|---|---|---|
| CSS 选择器高级用法 | querySelector / 组合选择器 | 批量定位广告元素 |
| MutationObserver | 监听页面元素变化 | 动态广告兜底 |
| 防抖（debounce） | 控制高频触发 | 扫描性能优化 |

## 六、广告过滤领域（🟡 建议）

| 知识点 | 一句话说明 | 在项目中的用途 |
|---|---|---|
| EasyList 规则语法 | ##隐藏 / #@#例外 / #?#程序化 | filter-parser.js |
| 广告与内容同源 | 为什么 URL 拦截拦不住 | 理解项目边界 |

## 七、网络原理（🟢 可选，但推荐了解）

| 知识点 | 一句话说明 | 在项目中的用途 |
|---|---|---|
| DNS / CDN | 域名解析与内容分发 | 理解 DNS 级拦截的局限 |
| HTTPS 与证书 | 加密通信 | 理解为什么只能看域名 |
| 同源策略 | 浏览器的安全模型 | 理解扩展权限的必要性 |

## 八、工具链（🟢 可选）

| 知识点 | 一句话说明 | 在项目中的用途 |
|---|---|---|
| 浏览器开发者工具（F12） | 调试网页 | 验证拦截效果 |
| Node.js | 运行 JavaScript 脚本 | 离线测试解析器 |
| Git | 版本管理 | 记录项目历史（建议尽早学） |
