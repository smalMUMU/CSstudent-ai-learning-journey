## 我怎么记

- **我写，AI 当教练**，不让 AI 替我写代码（规矩见 [`与AI协作原则`](./04_参考资料/与AI协作原则.md)）
- **每条记录写"我原本怎么理解、错在哪"** — 错的初始理解才是后面学习发生的原因
- **判据是配对测试**：当下写得出 ≠ 会，**隔 3 天不看还能写**才算会
- **结论落进文件** — 对话会被压缩，写下来的才算留下
- **AI 说话要有事实依据** — 评价我的代码前必须先读原文；指不出「文件+行号」就标"我猜"

实测：高数 Day 2 学完隔了 13 天没碰，靠复盘捞回来了。
