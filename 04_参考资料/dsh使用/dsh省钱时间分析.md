## 三、最省钱使用时间表（照这个安排）

| 要做的事 | 推荐时间 | 原因 |
|---|---|---|
| **刷题复盘 / 让 agent 写大段代码** | **凌晨 00:30–08:30** | output+reasoning 最重 → 低谷半价，省最多 |
| **批量任务 / 一次做完项目拆解、写文档** | **周末全天** | 周末全天低谷价，怎么用都便宜 |
| **轻量闲聊、查资料、问答** | 任意时间 | output 低，峰谷价差影响小 |
| **算法/推理重的活** | 挪到低价窗口，别堆 22:00–23:00 | 避开"贵价 + 重活"叠加 |
| **避免** | **22:00–23:00 干重活** | 最贵档 + 最重输出，双重大头 |

### 非时段省钱（往往比时段更省）
1. **吃缓存**：输入几乎全是缓存命中（6.7M–10M token）→ **少开新会话、继续同一会话** = 输入几乎免费。
2. **压 output + reasoning**：让 agent **少写废话、只给结论**，别长篇 dump 代码。
3. **用便宜档位**：8-24 花 ¥0.04 说明存在便宜路径，重活挑性价比高的 model / preset。

## 四、一句话
> **最省钱 = 凌晨 00:30–08:30（或周末全天）干活，把"输出多、要推理"的重活放进去；
> 晚上 22–23 点那种又贵又重的锋，尽量挪走或只做轻量的。**
