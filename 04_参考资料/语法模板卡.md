## 一、最常用的固定写法（基础）

### 导入模块
```python
import json                  # 整个模块
import os
from 模块名 import 名字       # 只拿某个名字用
from tools import run_tool   # 从 tools 文件拿 run_tool
```

### 定义函数（def）
```python
def 函数名(参数1, 参数2):
    ...                      # 函数体（要缩进 4 空格）
    return 结果
```

### 变量 = 函数(...)（右边先算，左边接结果）
```python
msg = call_llm(messages, TOOLS)     # msg 接住函数返回
```

### 字典 dict `{}`（键值对）
```python
d = {"name": "小明", "age": 18}
d["name"]          # 取值（没这个键会报 KeyError）
d.get("name")      # 安全取值（没这个键返回 None，不报错）
```

### 列表 list `[]`（有序集合）
```python
lst = ["a", "b"]   # 多个元素用逗号隔开
lst.append("c")    # 往末尾加一个
for x in lst:      # 遍历：x 依次 = 每个元素
    print(x)
```

### 循环
```python
while True:        # 无限循环（配合 break/return 结束）
    ...
for x in 列表/字符串:   # 遍历每个元素
    ...
```

### 条件判断 if / elif / else
```python
if tool_calls:        # 有内容(非空/非None) → 真
    ...
else:
    ...
```

### 字符串拼接
```python
s = "A" + "B"                 # 拼字符串
s = f"结果：{x}"             # f-string：把变量塞进字符串（推荐，好用）
s = str(列表)                 # 把列表/对象转成字符串
```

### 输出 / 输入
```python
print("hi")           # 打印
x = input("提示:")     # 显示提示，等你输入，返回字符串
```

### 入口守卫（只有直接运行才执行）
```python
if __name__ == "__main__":
    print(run(input("你:")))
```

## 二、Agent 项目用到的模板

### 工具说明书 TOOLS（给模型看的 JSON）
```python
TOOLS = [{"type": "function", "function": {
    "name": "calc",
    "description": "计算数学表达式，如 '12*7'",
    "parameters": {"type": "object", "properties": {"expr": {"type": "string"}},
                   "required": ["expr"]},
}}]
```

### 真正干活的工具函数
```python
def calc(expr: str) -> str:
    return str(eval(expr))        # 演示用；别直接 eval 不可信输入
```

### run_tool：按名字分发到对应工具
```python
def run_tool(name, args_json):
    args = json.loads(args_json) if args_json else {}   # 参数是JSON字符串→转字典
    if name == "calc":
        return calc(args["expr"])
    return "未知工具: " + name
```

### 系统提示词 SYSTEM
```python
SYSTEM = "你是一个 agent。可用工具:" + str([t["function"]["name"] for t in TOOLS])
```

### 初始化对话记录 messages
```python
messages = [
    {"role": "system", "content": SYSTEM},
    {"role": "user", "content": user_input},
]
```

### 调模型的函数 call_llm（DeepSeek 版，urllib 发 POST）
```python
import os, json, urllib.request
API_KEY = os.environ.get("DEEPSEEK_API_KEY", "")
BASE_URL = "https://api.deepseek.com/chat/completions"

def call_llm(messages, tools=None):
    body = {"model": "deepseek-chat", "messages": messages}
    if tools:
        body["tools"] = tools
        body["tool_choice"] = "auto"
    req = urllib.request.Request(BASE_URL,
        data=json.dumps(body).encode("utf-8"),
        headers={"Authorization": "Bearer " + API_KEY,
                 "Content-Type": "application/json"})
    with urllib.request.urlopen(req, timeout=60) as resp:
        data = json.loads(resp.read().decode("utf-8"))
    return data["choices"][0]["message"]
```

### agent 循环（核心）
```python
def run(user_input):
    messages = [
        {"role": "system", "content": SYSTEM},
        {"role": "user", "content": user_input},
    ]
    while True:
        msg = call_llm(messages, TOOLS)
        messages.append(msg)                     # 记下模型这步(tool_calls)，必须
        tool_calls = msg.get("tool_calls")       # 有没有"要调工具"？没有→None
        if tool_calls:                           # 有清单 → 处理工具
            for tc in tool_calls:
                name = tc["function"]["name"]
                args_json = tc["function"]["arguments"]
                out = run_tool(name, args_json)
                messages.append({"role": "tool",
                                 "tool_call_id": tc["id"],   # 必须对上号，否则报错
                                 "content": out})
            continue                             # 回下一轮，让AI看到结果
        return msg.get("content")                # 直接回答 → 结束
```

## 三、易混对照
| 容易混 | 区别 |
|---|---|
| `msg["k"]` vs `msg.get("k")` | `["k"]` 没键会**报错**；`.get("k")` 没键返回 **None** 不报错 |
| `json.dumps` vs `json.loads` | dumps = 对象→JSON文本；loads = JSON文本→对象 |
| `content=变量` vs `content="变量"` | 变量（不带引号）；字面量字符串（带引号） |
| 单个元素列表 vs 元组 | `[x]`是列表、`(x,)`才是单元素元组（带逗号） |
| `import os` vs `from os import ...` | 后者直接拿名字用，不用写 `os.` 前缀 |
